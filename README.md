# 📔 논문일기 — Student / Teacher Quest (SLOW PAPER 트랙)

**학습 아크:** 표현학습(MAE) → LLM 백본(DeepSeek) → 구조적 출력(DETR) → 시각-언어(LLaVA) → 예측적 월드모델(JEPA)

**기간:** 2026.10.14 ~ 11.05 (AIFFEL 리서처 19기 SLOW PAPER 구간, Day 65~81)
**연동:** AIFFEL Sub QUEST / SLOW PAPER와 **분리 운영** (개인 독립 트랙)
**순서:** 원래 아크 순서 유지

**운영 방식 (혼합):**
- **세션 시작** — 선생님(Sisyphus)이 Socratic 퀘스트 질문 제시 → 학생이 답변
- **세션 끝** — 학생이 Feynman 방식으로 설명 → 선생님이 꼬리질문/반박 → 이해 갭 교정
- **기록** — `DayNN_주제.md` 노트에 요약/수식/의문점 저장
- 노트의 `나의 답변`, `Feynman 설명`, `의문점`은 **본인이** 채우고, `채점 & 교정`은 선생님이 채운다
- **비교 원칙:** ablation은 **같은 시스템·도메인 안에서 변수 하나만** 바꿀 때만 성립 (vision끼리 / NLP끼리 / 멀티모달끼리). 도메인 교차 숫자 비교는 금지

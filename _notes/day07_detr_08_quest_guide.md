## Q1. 매칭이 학습을 대체한다

**(a)** 앵커의 할당 규칙과 달리 **헝가리아 알고리즘(최적 양자택일 매칭)**을 손실 앞단에 쓰는 이유를, 실습 [A]의 **순진 그리디 중복 비율 31.6%**와 **그리디가 optimal을 이긴 시행 0/500**을 근거로 설명하라.
**(b)** 매칭 비용은 **확률**(−p̂), 손실은 **로그 우도**(−log p̂)를 쓴다. 원문 §3.1의 근거 문장을 인용하고, 왜 손실에서는 무한대(−log p→∞)가 허용되어도 매칭에서는 안 되는지 **유계성·측정가능성(commensurability)** 관점으로 서술하라.
**(c)** ∅ 하향 10은 무엇을 조절하는가 — 실측 [C]의 격차(배경 항 **39.9x → 4.0x**, 1장 합계 391.3 → 39.8)와 COCO 평균 7객체(⇒ N=100 슬롯 중 ∅가 대다수)를 근거로 답하고, **이 조치가 무엇을 해결하지 못하는가**(배경 비중 98.1% 잔존)도 밝히라.

## Q2. 두 박스 손실의 역할 분리

**(a)** 같은 15% 상대 오차에서 L1은 대형/소형 **9.44x**로 갈렸고 GIoU는 **1.000x**였다(실측 [B]). 02 자료의 **스케일 불변성 증명**이 무엇을 해결하는지, 그리고 L1이 **불변하지 않는** 이유를 수식으로 서술하라.
**(b)** Table 4(L1만 35.8 / GIoU만 39.9 / 둘 다 40.6, AP_L 57.9·57.9·60.2)에서 **GIoU만으로 거의 다 오는 이유**를 해석하라. 특히 APS 13.7(←19.9)과 APL 57.9가 어떻게 나뉘는지.
**(c)** 그래도 둘 다(40.6)가 최고인 **0.7 AP**는 어디서 오는가 — 두 손실의 **역할 분리**로 답하라. (L1=정밀 좌표 항, GIoU=크기 균형 앵커 — 이 구분이 맞는지, 아니면 다른 설명이 필요한지 판단해라.)

## Q3. 인코더는 무슨 일을 하나?

**(a)** Table 2(인코더 0/3/6/12층 → 36.7/40.1/40.6/41.6 AP)에서 **0층일 때 −3.9 AP, AP_L −6.0**이다. 논문의 가설(**인코더는 인스턴스 분리(disentanglement) 담당**)을 Fig 3(마지막 인코더 층 attention이 인스턴스를 분리해 보인다)과 연결해 설명하라. 왜 손해가 **큰 물체 쪽**에 더 큰가.
**(b)** Table 3의 두 수치를 함께 읽어라: 공간 pos enc를 **전부** 제거하면 **−7.8 AP(32.8)**, **인코더에서만** 제거하면 **−1.3 AP(39.3)**. 이 차이(7.8 vs 1.3)가 인코더 attention의 성격(내용 중심 vs 위치 중심)에 대해 무엇을 말하는가? 참고: "sine at input"(1회 추가)은 −1.4로 **매 층 추가**가 기본이다.
**(c)** FFN 제거 실험(**−2.3 AP**, 41.3M → 28.7M, transformer 10.8M만 남음)에서 attention만으로는 왜 부족한지 서술하고, 이 결과가 Table 2·3과 어떻게 **일관된 하나의 그림**으로 합쳐지는지 정리하라.

## Q4. 100개의 슬롯이 학습하는 것

**(a)** Fig 7: 각 쿼리가 지역·박스 크기에 **여러 모드**로 특화하면서도 **모든 슬롯이 '화면 전체 박스' 모드**를 갖는다. 이것이 세트 예측 훈련(헝가리아 매칭)과 어떻게 양립하는지 설명하라. (논문은 이 현상을 COCO의 객체 분포 탓으로 돌린다 — 이 해석이 납득되는지.)
**(b)** 부록 Fig 12: 같은 클래스를 격자 반복 배치했을 때 **50개까지는 전부 검출**하지만 **100개를 놓으면 평균 30개만** 찾는다. 논문은 이것을 **OOD로 해석**하고 "과적합 증거는 아니다"라고 결론짓는다. 이 해석을 **비판적으로** 평가하라 — 반례가 될 수 있는 상황은?
**(c)** Fig 5(기린 24마리, 학습 최대 13) 일반화가 (b)의 한계와 **어떻게 함께** 읽히는가. "클래스별 슬롯 과적합은 아니다"라는 논문 결론을 정확히 인용해 답하라.

## Q5. RT-DETR — 병목 인식이 설계를 바꾼다 (real-time 축)

**(a)** Deformable-DETR에서 **인코더가 GFLOPs 49%인데 AP 기여는 11%**다. 이 병목 인식에서 나오는 하이브리드 인코더 설계(**AIFI = S_5에서만 self-attention**, **CCFF = conv 기반 융합**)를 RT Table 3 ablation(A 43.0/7.2ms → B 44.9/11.1 → C 45.6/13.3 → **D 46.4/12.2**(분리) → **D_S5 46.8/7.9** → E 47.9/9.3)으로 설명하라. 특히 **D→D_S5에서 "지연 −35%인데 AP은 +0.4"** 가 나온 것이 논문의 어떤 논리를 증명하는가, 그리고 AIFI가 **해상도가 가장 낮고 의미가 가장 풍부한** 레벨에만 붙는 이유(논문 문장 인용).
**(b)** Table 4: vanilla(분류 점수만) 47.9 AP → uncertainty-minimal 48.7(**+0.8**), Prop cls 0.35%→**0.82%**, Prop both 0.30%→**0.67%**. Fig 6 산점도(분류 점수 vs IoU 점수)에서 보라(uncertainty)가 **우상단**에 모이는 것이 무슨 뜻인지, 그리고 138%/120% 밀도 차이가 말해주는 것을 서술하라. **여기에 함정 1개**: 논문의 선택 기준과 공개 코드(`.topk(enc_outputs_class.max(-1).values, 300)`)가 다르다는 점을 06 자료에서 인용해 설명하라 — 그러면 이 기도는 *무엇*을 바꾼 것인가.
**(c)** Table 5: **재학습 없이** 디코더 깊이를 바꿔 6층 53.1 AP/9.3ms → 5층 53.0 AP/8.8ms로 속도를 조절할 수 있다. 이게 가능한 **구조적 이유**(원문 §3.2의 aux decoding loss)를, 그리고 **5층 → 6층의 기여가 0.1 AP에 불과**한 이유(인접 층 간 AP 차이가 층이 올라갈수록 줄어든다)를 설명하라. **07 데모에서 이 구조가 재현된 결과**는 무엇인가(단, 데모의 깊이 곡선은 논문과 **반대** 방향이었다 — 그 차이를 어떻게 해석하는가).
**(d)** 그래도 **AP_S가 YOLOv8-L보다 0.5 낮다**(34.8 vs 35.3). 논문 Limitation의 표현을 인용하고, 이 한계가 **Day 08(Deformable)·Day 10(DINO-DETR/RT-DETR)** 중 어디서/how로 이어지는지 서술하라. (아니면 이 한계는 3D로 가면서 더 어려워지는가 — `3D_OBJECT_DETECTION_지도.md` 참고)

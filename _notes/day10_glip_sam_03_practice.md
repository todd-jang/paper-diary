## 1. GLIP — 검증 V1 — 토큰 평균의 분산 감소 (§3.1)

**논문 명제**: phrase 확률 = 토큰(확률) 평균. sub-word가 클래스 방향의 '조각'만 담는 한, 표본평균의 분산은 단일 토큰의 ~1/K.

**방법**: 클래스별 K=4개 토큰 = a·W_c + σ·u_ck (σ 전 클래스 동일, 노이즈 방향 U 고정). 잔여 노이즈 비율 = ‖mean u‖²/mean‖u_k‖²를 실측, 기대값 1/K=0.25와 대조. σ=0.0744는 영역 제약(프로토타입 노이즈 ≈ 0.35·a)을 만족하도록 스케일링 법칙 σ = 0.35·a/√(D/K)로 고정.

**실측**
```
resid_single 0.3651   resid_mean 0.0905   ratio 0.2479   expected 1/K = 0.25
검색 정확도: 토큰평균 프로토타입 0.7500 > 단일 토큰 0.6875
```

**읽는 법** — 실측 비율 0.2479는 기대값 0.25와 거의 일치(K=4 고정의 '보장 방향'), 평균 프로토타입으로 정확도도 우위. 노이즈가 카테고리별 동일 분산(λ 격차 없음)이므로 이는 **순수한 통계 보장의 확인**이다.

## 2. GLIP — 검증 V2 — 로짓 스왑 동등성 (App. §B)

**논문 명제**: 닫힌 분류기 W → 프롬프트 임베딩 P로 스왑(S=O·Pᵀ)해도 성능 보존(전/후 COCO val 49.4 AP).

**방법**: σ=0에서 P̄_c = a·W_c (전 클래스 동일 스케일)는 모든 로짓을 같은 배율로 — **argmax 불변 항등식**. σ>0 구간은 공통난수(U 고정) 측정: 점수선이 σ에 선형 → 교차 최대 1회 → agreement 비증가(구조). 점수는 cos이 아닌 **내적**(cos 분모가 σ에 비선형이라 단조성이 깨짐).

**실측**
```
σ      = 0.0000  0.2000  0.5000  1.0000
agree  = 1.0000  0.6719  0.3438  0.2344
identity_at_sigma_zero: True   monotone_nonincreasing: True
```

**읽는 법** — σ=0 동등성은 '정리'로 통과(측정이 아님), σ>0에서 agreement는 측정값으로 단조 감소. **프롬프트 토큰 추정이 완벽(σ→0)하면 스왑은 무손실** — App. §B 동등성의 방향.

## 3. GLIP — 검증 V3 — 딥퓨전(O^{t2i} 여입)의 조건부 이득 (§3.2 Eqs. 4–6 · Table 8 방향)

**논문 명제**: 컨텍스트 여입 퓨전이 late fusion(고정 피처 직접 투영)보다 낫다 — 단, 이득은 **학습된 X-MHA 어텐션**이 정답을 조준할 때 나온다.

**방법**: 프롬프트 쪽(토큰·프로토타입)은 late/early 공유 → 이득이 피처 정제에서만 나온다고 분리. 이미지 피처 손상 τ(미학습 리전 피처 아날로그) × 어텐션 조준도 β(정답 클래스 질량 우위) 2요인 스윕, 업데이트 O ← O + α·(질량 가중 토큰 벡터), 지표 = 정답 MRR(내적, S=O·Pᵀ). **β=0(균등 어텐션)은 시그널이 정확히 0인 대조군**. 판정은 δ(β=1.0, τ=최대) > 0 이고 > 대조군.

**실측 (Δ = early − late MRR, 200 trials)**
```
β(조준도)   τ=0.35     τ=0.60     τ=0.85
β=0.0      -0.0244    -0.0114    -0.0035   ← 대조군: 이득 없음(노이즈만)
β=0.5      +0.0329    +0.0646    +0.0558   frac_early≥late = 1.0
β=1.0      +0.0582    +0.1291    +0.1155   frac_early≥late = 1.0
판정: δ_top = +0.1155  >  δ_ctrl = -0.0035  → PASS

[관측] 무학습 softmax 어텐션(γ=4): -0.0305 / -0.0425 / -0.0322 (판정 불포함)
```

**읽는 법** — late fusion MRR은 손상과 함께 0.92→0.61로 무너지고, **조준된 어텐션(β≥0.5)에서만 200/200 시행에서 early ≥ late**. β=1.0에서 마진 항등식(Δ마진 ≈ α·a²·(m_y − m_j)) 예측과 부합. 반대로 **무학습 softmax는 전 τ에서 음수** — 점수 노이즈의 볼록성(E[e^{γX}] 팽창) 때문에 오답 토큰 이상치가 어텐션을 잠식한다. **이것이 GLIP 이득의 근원이 학습 가능한 X-MHA 투영임을 보여주는 증거**다(합성 세계의 방향 확인일 뿐임을 명시).

## 6. SAM — 검증 V2 — 20:1 최소손실 ↔ 최대 IoU 대응 (§3)

**논문 명제**: 디코더 손실 = focal : dice = **20:1** — 이 3중 출력에서 '원하는 마스크'를 손실 argmin으로 고를 수 있다.

**방법**: 후보 3 × GT 3 IoU 행렬과 손실 행렬(20:1)을 계산, 각 후보에서 argmin(손실) GT == argmax(IoU) GT를 확인.

**실측**
```
IoU 행렬(행=후보 whole/part/subpart):
  [0.8914  0.3665  0.0950]
  [0.3503  0.8519  0.3043]
  [0.1066  0.2593  1.0000]
argmin(손실, 20:1) = [0, 1, 2] == argmax(IoU) = [0, 1, 2]   → 3/3
```

**읽는 법** — 대각 우위가 명확(0.89/0.85/1.00)하고, 20:1 구성의 손실 argmin이 이를 정확히 식별. **손실 구성이 '지시 해석'을 복원하는 기제**의 방향.

## 7. SAM — 검증 V3 — 다중 프롬프트 예외 (App. §A, 중요)

**논문 명제**: *"we only predict a single mask when more than one prompt is given... This fourth mask is never returned for a single prompt and is the only mask returned for multiple prompts."*

**방법**: 점+박스 프롬프트 → 박스가 개체 크기를 고정하므로, 박스로 구속된(clipped) 레벨-셋 중 **박스 면적과 일치하는 것을 단일 출력**으로 방출(디코더의 box 토큰 결합 아날로그; GT 기반 선택 없음 — 그것은 GT를 엿보는 치팅이므로 의도적으로 배제).

**실측**
```
n_outputs_single_prompt = 3        n_outputs_point_plus_box = 1
box_head_matches_box_extent = True
IoU vs part GT:  점만 0.8519  →  점+박스 1.0000
```

**응는 법** — 프롬프트 정밀화(점 → 점+박스)가 part GT와의 IoU를 0.8519 → 1.0000로 끌어올리는 방향 + '다중 프롬프트=1출력' 구조가 그대로 재현.

## 8. SAM — 검증 V4 — 손실 가중치 스윕 (판정은 논문값 20:1에서만)

**방법**: (1:0)/(1:1)/(20:1)/(0:1) 네 구성에서 V2 대응률을 재계산. 20:1만 판정, 나머지는 관측.

**실측**
```
argminGT == argmaxIoU:  focal20:dice1 → 3/3   focal1:dice1 → 3/3
                        focal1:dice0 → 0/3   focal0:dice1 → 3/3
```

**읽는 법 + 진단** — **순수 focal(1:0)은 완전 붕괴**. 원인: eps(1e-7) 클립 포화로 픽셀당 패널티 상한(α·log(1/ε) ≈ 4.03)이 걸려 '깊게 놓친 128픽셀'과 '경계에서 놓친 12픽셀'을 구별하지 못함(h4.8 실측: G1 깊은 FN 128px vs G2 경계 FN 12px에서 argmin이 반전). **영역 겹침(IoU) 구조는 dice 항이 담당**한다 — focal은 경계 신뢰도, dice는 겹침 기하. 논문이 focal+dice 조합(비율 20:1)을 쓰는 이유의 합성 세계 버전. 20:1은 나이프-엣지가 아님(1:1도 3/3) — 비율 자체가 논문 명시값이라는 점만 판정.

## 10. 이 데모의 한계 (반드시 함께 읽을 것)

1. **D=64 합성 세계** — 실제 인코더의 차원(256+)·다중 head·연산 위치 편향이 없다. 얻는 것은 방향, 잃는 것은 크기.
2. **V3의 '조준 어텐션'은 학습된 X-MHA의 이상화** — 실제 모델에서 조준도는 훈련의 결과다. 이 데모는 "조준되면 마진 항등식대로 득감, 조준 안 되면(무학습 softmax) 오히려 손실"이라는 **조건 구조**만 증명한다.
3. **SAM 후보는 레벨-셋 헤드의 아날로그** — 실 SAM은 변환기 디코더에서 프롬프트 임베딩을 교차 어텐션으로 투사한다. 여기서는 기하 구조만 대응시켰다.
4. **모든 검증 통과 값은 시드 42의 결정론 귀결**일 뿐, 통계적 유의성 검정이 아니다.

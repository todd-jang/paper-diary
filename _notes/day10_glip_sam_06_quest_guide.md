## Q1. 텍스트 로짓이 분류 로짓을 대신할 수 있다는 것을 어떻게 증명하나

**(a)** GLIP의 동등성 주장(App. §B: closed-set 분류기 W → 프롬프트 임베딩 P 스왑, 전/후 COCO val 49.4 AP)을 인용하고, 이것이 왜 텍스트(프롬프트) 임베딩의 학습-시간 역할과 추론-시간 역할을 하나로 묶는 설계 순서인지 설명하라.
**(b)** 스왑이 **정확히 등가**가 되는 조건 2가지(공유 스케일 + 완벽 추정)를 수식으로: 평가 점수 변경은 공통 배율(선형 변환)뿐이어서 argmax 불변 · 점수가 σ에 선형 → agreement 비증가. 실습 V2 실측(σ=0 agreement 1.0000 단일성, σ>0 비증가: 1.0 → 0.6719 → 0.3438 → 0.2344)을 근거로 붙여라.
**(c)** 토큰 평균이 프롬프트 근사의 **정확도**를 어떻게 살리는지 — 실습 V1(잔여 노이즈 비율 실측 0.2479 ≈ 1/K=0.25, 검출 확률 0.6875 → 0.75)을 인용하되, 이것이 "측정"이 아니라 **분산 공식의 기대값**임을 명시하라.
**(d)** **경계**: 스왑 등가성이 무너지는 실제 상황(카테고리별 토큰 스케일 불균형, 추정 오차 σ>0)을 논의하라. GLIP이 이를 어떻게 흡수하는지(딥퓨전, Q2) 연결하라.

## Q2. 딥퓨전(O_t2i)은 왜 비싼데도 도입했나

**(a)** Table 7 비용(딥퓨전: GLIP-T 추론 2.52FPS/2.4GB vs 비퓨전 4.84FPS — **해상도 미기재**라 절대 비교 금지 + 내부 상대비만 유효)을 인용하라.
**(b)** X-MHA 딥퓨전의 구조적 이득: 언어 문맥(O_t2i의 컨텍스트)이 **이미지 피처 자체를 정제**한다. 실습 V3 실측 — β(조준도)×τ(피처 손상) 스윕 — 조준 어텐션 β≥0.5에서만 200/200 시행에 early ≥ late, 무학습 softmax는 전 τ 구간에서 음수 — 를 근거로 **"이득의 근원은 학습된 X-MHA"**를 논증하라.
**(c)** Table 5의 소거(검출 데이터 2.66M 추가 → 46.3/COCO·15.0/LVIS APr vs O365+GoldG → 46.7·17.7)와 §4.4 문장(LVIS APr 20.8 vs 15.0)을 인용해, **딥퓨전이 아니라 grounding 데이터**가 rare를 끌어올린 관계로 읽고, Q2(b)의 구조(데이터가 X-MHA의 조준도를 학습시킨다)와 연결하라.
**(d)** **경계**: 이 데모가 절대로 증명하지 못하고 논문이 "증명"하지도 않는 것(실제 모델의 조준도 = 학습 결과라는 점)을 명시하라.

## Q3. ODinW 스윕이 보여주는 것과 보여주지 않는 것

**(a)** Table 11의 세 역전(초록): zero-shot GLIP-L **52.1** > 10-shot 지도 DyHead **50.8** / 1-shot GLIP-L **59.9** ≈ 완전 지도 DyHead **60.8** / zero-shot GLIP-T **46.5** > 5-shot DyHead **46.4** — 표에서 직접 확인하라.
**(b)** 스케일 뒤집기의 내부: GLIP-T(A) 28.7(0-shot)이 DyHead 1-shot(33.8) 이하임을 인용하고, **언어-이미지 사전학습이 없으면 zero-shot 강세가 사라진다**는 조건을 도출하라(Table 5와 같은 방향).
**(c)** 표 수치만으로는 few-shot 필요성이 사라진다고 말하기 어렵다: GLIP-L 10-shot 64.9 vs 완전 지도 68.9. 프롬프트 튜닝(67.9, Tables 12–13)이 이 마지막 구간을 어떻게 메우는지 설명하라.
**(d)** 실습 V4의 청킹 검증(40 카테고리 청크, coverage 1.0, 일치 1.0)을 인용해 **대형 어휘(LVIS 1,203)가 실제로 동작하는 방식**을 App. §C와 연결하라.

## Q4. SAM의 "모호성 3분해"와 20:1 손실은 어떻게 반대의 구조인가

**(a)** SAM의 애매성 설계(§3): 3 출력(whole/part/subpart) 학습 = 3마다 손실 계산하되 **최저손실에서만 역전파** + **estimated IoU 토큰**으로 랭킹. 논문 문장("lowest loss", Fig. 2)을 인용하라.
**(b)** **다중 프롬프트 예외**(App. §A: >1 프롬프트면 **1개**만 출력)를 정확 인용하고, 실습 V3 실측(점+박스 → 1출력, 박스 면적 매칭, IoU 0.8519 → 1.0000)으로 프롬프트 정밀화가 모호성을 해소하는 방향을 설명하라.
**(c)** 20:1 손실의 각 항의 분업: focal(경계 신뢰도) vs dice(영역 겹침). 실습 V4(순수 focal 0/3 붕괴 — ε 클립 포화 4.03 픽셀당 상한으로 깊은 FN 128px vs 경계 FN 12px 미구분, dice 포함 구성 3/3)를 근거로, **20:1은 편의 아니라 겹침 기하를 살리는 조합**임을 논증하라.
**(d)** 20:1이 **나이프-엣지(특정 비율이어야만 통과)가 아니라**는 실습 관측(1:1도 3/3)을 인용하고, 논문이 20:1을 명시만 했을 뿐 그 근거를 제시하지 않는다는 점과 대조하라.

## Q5. 데이터 엔진: 모델이 곧 라벨러일 때 무엇이 되는가

**(a)** 3단계 수치(§4/Fig. 6): 120k 이미지/4.3M 마스크(20→44, 34s→**14s** 시간/마스크) → +180k/10.2M(44→**72**) → 32×32 격자 전체+crop/**1.1B**(평균 ~100). **99.1% 자동**을 인용하라.
**(b)** 품질 벨트(§B: 예측 IoU 88.0 이하 제거, 안정성 IoU 95.0, ≥95% 전역 마스크 제거, NMS 0.7, 100px 클러스터 제거)와 검증(500장 재측정, **94% pairs IoU>90%**, 기존 인간 합의 **85–91%** 대상)을 인용하고, **기존 최대 데이터셋 대비 마스크 400×·이미지 11×**의 의미를 서술하라.
**(c)** §7.6 소거: 1M 이미지(~10%)면 SA-1B 전체와 같고, 자동 마스크 전용 학습과 차이 ~0.5 mIoU 미만. 데이터 규모가 아니라 **파이프라인 설계**가 품질을 결정하는지 논의하라.
**(d)** LVIS 대비 rare 우위(65.8 vs 58.3)와 에지 미달(BSDS ODS 0.768 vs 0.840)을 **같은 논문의 두 얼굴**로 서술 — "모든 것에 더 낫다"는 아니다. 23 데이터셋 1점 평가(16승, oracle 애매성 해소 시 전체 승)까지 포함하라.

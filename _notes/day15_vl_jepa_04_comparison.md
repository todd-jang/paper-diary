# 04 · 비교표 — MAE vs LLaVA vs VL-JEPA 패러다임 비교

> **대상**: 비전-언어 및 자기지도학습의 3대 패러다임 비교  
> **세션 일자**: 2026.11.02(월) ~ 11.03(화)

---

## 1. 패러다임별 비교

| 비교 항목 | MAE (Day 01) | LLaVA (Day 13) | VL-JEPA (Day 15-16) |
| :--- | :--- | :--- | :--- |
| **핵심 목적** | 비전 표현 사전학습 | 멀티모달 인스트럭션 튜닝 | 비전-언어 월드 모델 (동역학 예측) |
| **타깃 공간** | 원시 픽셀 (Pixel Domain) | 텍스트 토큰 (Token Domain) | **잠재 표현 공간 (Latent Space)** |
| **모델 유형** | 생성/복원형 (Generative) | 자기회귀 생성형 (Autoregressive) | **조인트 임베딩 예측형 (JEPA)** |
| **손실 함수** | MSE (픽셀 손실) | Cross-Entropy (언어 모델링) | $L_1 / L_2$ / Cosine Distance |
| **디코더 구조** | 경량 픽셀 디코더 | 거대 자기회귀 LLM (Vicuna 등) | **가벼운 잠재 예측기 (Predictor)** |
| **텍스트 역할** | 없음 (순수 비전) | 메인 출력 및 인터랙션 | **시각 예측을 가이드하는 조건 (Condition)** |
| **장점** | 단순하고 직관적 | 뛰어난 언어 상호작용 | **비가역적 노이즈 무시, 효율적 추론** |
| **단점** | 고주파 픽셀 노이즈에 용량 낭비 | 토큰 생성 비용 $O(N)$, 환각 | 픽셀 자체 렌더링 불가 |

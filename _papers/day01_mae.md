## ✅ 채점 & 교정 (선생님이 채움)

> 학생 답변: "모름" → 전면 강의 진행.

**Q1 (75% vs 15%)** — 언어는 정보 밀도 높아 15%로 충분히 어렵지만, 이미지는 패치 간 중복이 커서 조금만 가리면 대충 복원됨. **75%**를 가려야 "전체 이해"가 필요한 어려운 과제가 됨.

**Q2 (마스크 토큰 X)** — 인코더는 **보이는 25%만** 처리. 어텐션은 토큰 수의 제곱 → `(0.25)²=1/16`로 계산·메모리 절감, 학습 3배+. 정보 없는 토큰에 어텐션 낭비도 제거.

**Q3 (가벼운 디코더)** — ① 픽셀 복원은 저수준이라 표현력 불필요 ② 디코더는 사전학습 후 **폐기**. 무겁게 하면 계산 낭비 + 인코더 표현 학습 동기 약화.

**Q4 (저수준→고수준)** — 75% 마스킹은 저수준 보간으로 못 채움. 최적 예측자는 조건부 평균 `E[x_i|x_S]` → 결합분포(물체·텍스처·맥락) 이해 필요. **과제 난이도가 고수준 이해를 강제.**

**Q5 (디코더 폐기)** — 인코더가 "표현" 담당, 디코더는 픽셀 복원 보조 전용. 다운스트림엔 인코더 특징만 필요. **MAE의 산출물은 인코더.**

**Q6 (MAE vs BEiT)** — BEiT=이산 토큰(dVAE, CE, 토크나이저 필요) / MAE=원시 픽셀(MSE, 토크나이저 불필요). MAE는 단순·빠름·스케일 용이, 대신 선형 프로빙은 약할 수 있음.

**총평:** 핵심 두 설계(비대칭 인코더-디코더 + 75% 마스킹)의 "이유"를 이해하는 게 목표. 아래 리퀴즈로 확인.

### 🔁 리퀴즈 기록 (재확인)
- **R1 (개념 확인)** — ⭕ (거의 정답)
- **R2 (연산 절감)** — ⭕ 정답: 인코더가 보이는 25%만 처리 → 어텐션 비용 `(0.25)² = 1/16`
- **R3 (특징 담당 주체)** — ❌ 학생 "디코더" → **정답: 인코더** (다운스트림 표현을 제공하는 것은 인코더)
- **R3' (재확인)** — 학생: *"디코더는 다운스트림에서 head만 붙여서 사용 가능하고, 인코더가 주요 특징추출을 담당"*
  - ✅ 맞은 부분: **인코더가 주요 특징 추출을 담당한다** (정확)
  - ❌ 틀린 부분: **"디코더에 head를 붙여 다운스트림에서 사용"** → 거꾸로. head는 **인코더**에 붙는다. 디코더는 다운스트림에서 **폐기**된다.
  - 📌 핵심 정정: **인코더 = (사전학습 후) 살아남아 특징을 제공하고 task head가 붙는 것 / 디코더 = 사전학습 전용(복원 보조), 끝나면 버림**
  - 비유: 인코더=실력, 디코더=연습문제집. 시험(다운스트림)에선 문제집 버리고 실력+답안지(head)만 씀.

## 🧩 핵심 메모 (정답 요약 — 답변 후 대조용)

**① 비대칭 인코더-디코더**
- 인코더는 **보이는 25% 패치만** 처리 (마스크 토큰 X) → 연산량 1/4
- 디코더는 latent + 마스크 토큰을 받아 픽셀 복원 (가볍게, 256-d)
- 무거운 인코더 + 가벼운 디코더 = 효율 + 성능

**② 높은 마스킹 비율 (75%)**
- 이미지는 패치 간 중복이 커서 조금만 가려도 주변에서 복원 가능
- 75%를 가려야 "전체 이해"가 필요한 어려운 자기지도 과제가 됨
- → 비대칭 구조와 결합 시 3배+ 빠른 학습

**③ 결과**
- ViT-H로 ImageNet-1K 87.8% (1K 데이터만 쓴 방법 중 최고)
- 다운스트림에서 지도학습 사전학습 능가, 좋은 스케일링

**④ 왜 픽셀 복원이 좋은 표현을 만드나 (직관)**
- 75%를 가리면 저수준 통계로는 못 채움 → 물체 형태/문맥/의미를 이해해야 함
- 즉 과제를 어렵게 만들어 **고수준 이해를 강제**함

## 🏁 Day 1 종료 요약 (선생님 정리)

**MAE 한 문장:** 이미지의 75%를 가리고 → **보이는 25%만 인코더에 넣어** 표현을 뽑고 → **가벼운 디코더**가 마스크 토큰과 함께 가려진 픽셀을 복원하도록 학습한 뒤 → **디코더는 버리고 인코더만** 다운스트림에 쓴다.

**학생이 계속 헷갈린 지점 (3회) → 최종 정정 (가장 중요):**
- 다운스트림에서 **살아남는 것은 인코더**. task head(분류기 등)는 **인코더**에 붙인다. (**디코더 ❌**)
- 디코더 = 사전학습 전용(복원 보조 도구) → 학습이 끝나면 **폐기**.
- 비유: 인코더 = 실력 / 디코더 = 연습문제집 → 시험(다운스트림)에선 문제집 버리고 **실력 + 답안지(head)**.
- **MAE의 진짜 산출물 = 인코더.**

**리퀴즈 결과:** R1 ⭕ · R2 ⭕ (0.25²=1/16) · R3 ❌→교정(정답: 인코더) · R3' 부분⭕ (인코더 특징추출 ✅ / head 부착 대상 ❌)

**직접 해보기(보너스) 완료:** ImageNet-1K 서브셋 FAIR MAE 충실 재현 → `day01_mae/minimae/`
- 14 클래스 / 15,956 train / 840 val, ViT-Tiny(3.34M), mask 0.75
- 사전학습 loss **1.0289 → 0.5387** (20 epoch, 단조 감소·수렴)
- 선형 프로빙 val_acc **39.76%** (14-way, 랜덤≈7%; 2 epoch 때 28.1% → 상승)
- 단위 테스트 `pytest -q tests` → **29 passed**

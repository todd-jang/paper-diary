## 📖 읽기 가이드 (염두에 두고 읽기)
- **핵심 대비 3가지**: ① KV 압축 방식(헤드 공유 GQA vs **저랭크 압축 MLA**) ② RoPE 위치(**decoupled 소채널**) ③ FFN(**잘게 + 공유**)
- MLA가 GQA와 다른 점은 "무엇을 줄이느냐"가 아니라 **"어떻게 줄이느냐"** — 왜 저랭크가 표현력 손실이 더 작은가?
- **흡수(absorption)** `A_i = W^UQ_iᵀ W^UK_i` 가 왜 "K,V를 계산조차 안 하게" 만드는가?
- RoPE를 `k^C`에 걸면 왜 흡수가 **깨지는가**? (행렬곱의 **비가환성**과 연결)
- **decoupled RoPE**가 왜 `d_h^R=64`라는 **작은 별도 채널**로 충분한가?
- DeepSeekMoE의 **fine-grained**와 **shared expert**가 각각 무엇을 해결하나(중복 제거 / 조합 폭발)?

## 🎯 오늘의 Socratic Quest (읽고 답하세요)

**Q1.** MLA는 KV를 **저랭크 잠재벡터 `c_t^KV`** 로 압축한다(식 9). GQA가 **KV 헤드를 공유**해 cache를 줄이는 것과 비교할 때, MLA의 **저랭크 압축**이 **표현력 손실을 더 작게** 만드는 이유는 무엇인가? "헤드를 묶는 것"과 "공통 저랭크 공간으로 접는 것"의 차이로 설명하라.

**Q2.** **흡수(absorption)** `q_t^Cᵀ k_s^C = (c_t^Q)ᵀ (W^UQ_iᵀ W^UK_i) c_s^KV` 가 성립한다. 이 항등식이 왜 **"추론 시 K, V를 materialize하지 않아도 됨"** 을 함의하는가? (그리고 W^UV는 어디로 흡수되나?)

**Q3.** RoPE를 `k^C`에 그대로 걸면 왜 위 흡수가 **깨지는가**? `RoPE(k_s^C) = R_s·W^UK c_s^KV` 로 썼을 때 `A_i` 가운데에 무엇이 끼어들어 흡수를 막는지 서술하라.

**Q4.** **decoupled RoPE**는 위치정보를 `q^R, k^R`(각 `d_h^R=64`) **소채널에만** 싣는다. 이 설계가 **(i) 흡수는 유지**하면서 **(ii) 위치정보는 보존**하는 이유는? 왜 `d_h^R`가 `d_h`(=128)보다 작아도 되는가?

**Q5.** **DeepSeekMoE**의 두 아이디어 — **fine-grained expert segmentation**(잘게 쪼개기)과 **shared expert isolation**(공유 전문가 분리) — 이 각각 어떤 문제를 해결하는가? (힌트: "조합 폭발"과 "공통지식 중복")

**Q6 (심화).** MLA는 KV cache를 줄이면서 **MHA보다 성능이 낮지 않다**(논문). 이 결과가 **"표현력과 효율은 트레이드오프"** 라는 통념에 던지는 반례는 무엇인가? KV의 **저랭크 구조**가 오히려 **정규화(regularization)처럼** 작동할 수 있다는 관점으로 설명하라.

## ✍️ 나의 답변 (본인이 채우세요)
- Q1. 차이는 **"표현 공간의 강제 공유" vs "정보 병목을 통한 재구성"** — GQA는 여러 Query 헤드가 동일한 KV 헤드 하나를 강제 공유(그룹이 볼 수 있는 정보가 문자 그대로 동일), MLA는 공통 저차원 잠재 공간에 투영 후 서로 다른 업프로젝션 행렬로 헤드별 K/V 재구성 → 헤드별 초점은 여전히 다름.
- Q2. (a) K를 만들지 않고도 K와의 내적과 같은 값을 얻는 것 — 업프로젝션이 선형이라 Query 쪽 업프로젝션과 결합 가능. (학생 후속) Value는 score와 달리 가중합의 대상이므로 흡수 위치가 다름.
- Q3. 흡수는 입력 무관 고정 행렬 A_i가 잠재 벡터 사이에 있는 것이 전제. RoPE를 걸면 R_s가 W^{UQ⊤}와 W^{UK} 사이에 끼어듦 → 결합법칙으로 접히지 않음.
- Q4. 흡수 성립 조건은 "c^Q와 c^KV 사이의 변환이 위치에 무관한 하나의 행렬로 접힐 것". RoPE의 R_s는 위치 종속성 때문에 이 조건을 구조적으로 깨뜨림. 그래서 RoPE를 잠재 벡터가 아닌 업프로젝션된 K의 일부 차원에만 적용하거나(decoupled RoPE), 별도 RoPE 전용 차원을 두는 방식으로 우회.
- Q5. 세분화된 전문가 분할은 **지식 혼재(knowledge hybridity)** 를, 공유 전문가 격리는 **지식 중복(knowledge redundancy)** 을 해결. (학생 후속) 혼재 해소 = 쪼갠 전문가를 토큰마다 top-K로 재조합 (C(160,6)≈2.1×10^10 vs C(64,2)=2016), 중복 해소 = 공통지식을 공유 전문가에 격리해 라우팅 전문가를 전문화에만 투자.
- Q6. MLA의 성공은 "정보를 덜 저장"이 아니라 저장된 정보의 **단위당 가치를 높인 것**. 저차원 잠재 공간은 중복을 제거하면서 재구성 능력은 유지하고, 흡수 메커니즘은 업프로젝션 오버헤드를 추론 경로에서 제거. 따라서 캐시 크기와 모델링 성능이 동시에 향상될 수 있음.

## ✅ 채점 & 교정 (선생님이 채움)

**Q1 (2026-10-18)** — 답변: "차이는 '표현 공간의 강제 공유'와 '정보 병목을 통한 재구성'. GQA는 여러 Query 헤드가 동일한 KV 헤드 하나를 강제 공유 → 그룹이 볼 수 있는 정보가 문자 그대로 동일. MLA는 공통 저차원 잠재 공간에 투영 후 서로 다른 업프로젝션 행렬로 헤드별 K/V 재구성 → 헤드별 초점은 여전히 다름" → **정답 (약 90%)** ✓✓
- ✓ **GQA = 강제 공유**: 그룹 내 K·V가 **문자 그대로 동일 벡터** — 정확. (그룹이 볼 수 있는 정보 자체가 동일 = 표현 공간 강제 동일화.)
- ✓ **MLA = 공통 잠재 + 헤드별 W^UK_i**: 헤드별 업프로젝션이 다르므로 **초점(attention pattern)이 유지**됨. 핵심 정확.
- ✓ "정보 병목을 통한 재구성" 프레이밍: "묶어서 버림" vs "접었다가 헤드별로 다시 펼침".
- **보강 ① (왜 접어도 손실이 적나)**: K,V는 **원래 저랭크 기원** — `k = W^UK W^DKV h` 경로상 h(5120)→c(512)를 거치며 처음부터 접혀 있음. 게다가 `d_c(512) ≥ d_h(128)` 이라 헤드별 키 복원은 사실상 무손실. 손실은 오직 **헤드 간 중복 정보**에서만 발생 → 원래부터 공유되던 것만 제거하는 셈.
- **보강 ② (정량)**: GQA 그룹당 K·V = `2·d_h = 256`을 그룹이 **같은 벡터**로 사용 / MLA는 토큰당 **576**으로 **128 헤드 전부 서로 다른 키** 구성 → **더 적은 차원으로 더 많은 헤드 다양성**.
- 한 줄: **"GQA는 헤드가 볼 세상을 똑같이 만든다(강제 공유); MLA는 공통 지도를 주고 헤드마다 다른 안경을 씌워준다(공통 잠재 + 헤드별 복원)."**

**Q2 (2026-10-18)** — 답변: "K를 materialize하지 않는다 = K를 만들지 않고도 K와의 내적과 같은 값을 얻는다는 뜻. 근거는 업프로젝션이 선형이고 Query 쪽 업프로젝션과 결합 가능하다" → **부분 정답 (약 60%)** → 후속 **"Value는 score와 달리 가중합의 대상이므로 흡수되는 위치가 다릅니다"** → **재평가: 정답 (약 95%)** ✓✓
- ✓ **(a) 핵심 정확**: 선형성 → 행렬 결합 `q^Tk = (c^Q)^T(W^UQ^TW^UK)c^KV`. "업프로젝션이 선형이라 결합 가능" = 그 이유 ✓. 행렬곱 결합법칙 하나로 K 계산 소멸.
- **(a) 보강**: 결합의 실용적 함의 — 추론 시 `K = W^UK c` 행렬곱 **자체를 건너뜀**. cache는 `c^KV`만, 스코어는 미리 접어둔 `A_i = W^UQ_iᵀW^UK_i`로 `c^Q → A_i → c^KV` 2단계(작은 행렬) 계산. 게이트/캐시/연산 모두 3개 → 2개.
- **(b) 수업 (학생 후속으로 흡수)**: `o_{t,i} = Σ_j a_{ij} v_j^C`, `v_j^C = W^UV c_j` 이므로 `o_{t,i} = W^UV(Σ_j a_{ij} c_j)`. 즉 **V도 미계산** — (1) 잠재벡터 가중합 `Σ a_{ij}c_j`(이미 cache에 있는 c만 사용) (2) 그 뒤 `W^O_i·W^UV` **합쳐진 행렬** 1회 적용. → **어텐션이 잠재 공간에서 직접 계산**되고 K·V **둘 다** 추론 경로에서 소멸.
- ✓ **재평가 정확한 포착**: K는 softmax **이전**(가중치를 만드는 쪽) → Query 쪽 `A_i`로 흡수 / V는 가중합 **이후**(합쳐지는 쪽) → 출력 쪽 `W^O_i·W^UV`로 흡수. **왜 안전한가**: V는 `a_{ij}` 계산에 개입하지 않으므로 가중합 뒤 흡수해도 어텐션 가중치 불변 → 무손실.
- 한 줄: **"가중치를 만드는 놈(K)은 softmax 전에 Query로 끌려가고, 가중 합쳐지는 놈(V)은 softmax 후에 출력으로 붙는다 — 흡수 위치가 정반대."**

**Q3 (2026-10-18)** — 답변: "`A_i = W^{UQ⊤}W^{UK}`라는 입력 무관 고정 행렬이 잠재 벡터 사이에 놓였는데, RoPE를 걸면 `R_s`가 `W^{UQ⊤}`와 `W^{UK}` 사이에 끼어듦 → `W^{UQ⊤}R_sW^{UK}` ≠ `W^{UQ⊤}W^{UK}`. 결합법칙으로 두 행렬을 먼저 곱하려면 그 사이에 아무 행렬도 없어야 하는데 R_s가 정확히 그 자리를 차지 → 'c^Q와 c^KV만으로 미리 접힌 행렬' 흡수 불성립" → **정답 (약 90%)** ✓✓
- ✓ **(a) 완벽 유도**: R_s의 **위치**가 정확함 — 결합법칙이 요구하는 "빈 자리"에 끼어들어 접기 불가. "입력 무관 고정 행렬" = 흡수의 전제조건을 정확히 짚음.

## 🧩 핵심 메모 (정답 요약 — 답변 후 대조용)

**① MLA = MHA + low-rank KV joint compression**
- KV를 **공통 저랭크 공간** `c_t^KV`(512)로 다운프로젝션(식9) → 업프로젝션으로 K,V 복원(식10-11).
- GQA(헤드 공유)와 달리 **헤드별 표현력 유지** → cache↓ + 성능↑.
- cache/토큰 = `(d_c + d_h^R)·l = 576×60 = 34,560` (MHA `1,966,080` 대비 **−98.2%**; 논문 headline −93.3%는 DeepSeek 67B 대비).

**② 흡수(absorption)**
- `A_i = W^UQ_iᵀ W^UK_i` 를 미리 접으면 `qᵀk = (c^Q)ᵀ A_i c^KV` → **K,V 미계산**.
- `W^UV`는 출력 측 `W^O`로 흡수. 실측 항등식 오차 `~1e-11`.

**③ decoupled RoPE**
- `k^C`에 RoPE 걸면 `R_s`가 `A_i` 가운데 끼어 흡수 불가(실측 오차 `4.6e-05` ≫ 0).
- 해법: RoPE를 **별도 `q^R,k^R`(`d_h^R=64`)** 에만 → C-부분 흡수 유지(실측 일치 `~3e-11`).
- `q=[q^C;q^R]`, `k=[k^C;k^R]`, 스코어 = `q^Cᵀk^C + q^Rᵀk^R`.

**④ DeepSeekMoE**
- `h' = u + Σ N_s shared + Σ g_{i,t} routed`, `g=Top-K(Softmax(uᵀe_i))`.
- **fine-grained** → 조합 폭발(표현력↑, 같은 활성 파라미터). **shared** → 공통지식 전담(라우팅 중복 제거).
- V2: N_s=2, N_r=160, K_r=6, expert hidden 1536 → **236B/21B**.

**⑤ 대표 수치**
- KV cache **−93.3%**, throughput **×5.76**, 학습비 **−42.5%**, 8.1T 토큰, 128K 문맥, 236B/21B.

# 02. 수식 유도 — 손실함수와 비대칭 구조의 수학적 분석

> MAE (He et al., 2022)의 핵심을 수식으로 분해한다.

---

## 0. 표기(Notation)

| 기호 | 의미 |
|---|---|
| `x ∈ R^{H×W×C}` | 입력 이미지 |
| `P` | 패치 크기, `N = HW/P²` | 패치 개수 |
| `x_i ∈ R^{P²C}` | i번째 패치(펼친 벡터) |
| `X = [x_1;…;x_N] ∈ R^{N×P²C}` | 패치 행렬 |
| `r` | 마스킹 비율 (MAE: 0.75) |
| `S` | **보이는** 패치 인덱스 집합, `|S| = (1-r)N` |
| `M` | **가려진** 인덱스 집합, `|M| = rN` (S ∪ M = 전체) |
| `D` | 인코더 임베딩 차원 |
| `f_enc, g_dec` | 인코더 / 디코더 함수 |

---

## 1. 패치 임베딩 = 선형 사상

각 패치를 선형 투영하고 위치를 더한다:

```
z_i = W_e x_i + b_e + e_i^pos ,     W_e ∈ R^{D × P²C},  e_i^pos ∈ R^D
```

행렬로: `Z = X W_e^T + 1 b_e^T + E_pos ∈ R^{N×D}`.

---

## 2. 마스킹 = 선택 행렬(selection matrix)

무작위 부분집합 `S` (크기 `(1-r)N`)를 뽑는 연산은 **선택 행렬** `P_S ∈ {0,1}^{((1-r)N) × N}`로 표현된다. 각 행은 표준기저 벡터(one-hot)다.

```
Z_S = P_S Z ∈ R^{((1-r)N) × D}          # 보이는 패치만 남김
```

이때 `Z = P_S^T Z_S + P_M^T Z_M` 로 복원 가능(순서는 섞여 있음). `P_S P_S^T = I`, `P_S^T P_S`는 대각 0/1 사영 행렬.

---

## 3. 인코더

인코더는 **오직** `Z_S`에만 작동한다 (마스크 토큰 없음):

```
H = f_enc(Z_S) ∈ R^{((1-r)N) × D}
```

> **핵심:** `Z_M`(가려진 토큰)은 인코더에 **입력되지 않는다**. 이게 "비대칭"의 정의다.

---

## 4. 디코더

복원할 전체 시퀀스를 만든다. 먼저 가려진 자리에 **공유 마스크 토큰** `m ∈ R^{D'}`을 채우고, 순서를 되돌린다(unshuffle):

```
H' = Unshuffle( [ proj(H) ; m·1_{rN}^T ] )  + E_pos^dec ∈ R^{N × D'}
```

- `proj(·)`: 인코더 차원 `D` → 디코더 차원 `D'` 선형 투영 (MAE: `D=768→D'=512`).
- `Unshuffle`: §2의 `P_S`가 만든 순서를 원래 패치 순서로 되돌리는 치환.

디코더 출력:
```
Y = g_dec(H') ∈ R^{N × D'}   →   x̂_i = W_d y_i + b_d ∈ R^{P²C}
```
i번째 출력 토큰이 i번째 패치의 **픽셀값**을 예측.

---

## 5. 손실 함수 — 가려진 패치에서만

가려진 집합 `M`에 대해서만 평균제곱오차(MSE):

```
             1
  L_MAE = ───────  Σ_{i∈M} ‖ x̂_i − x_i ‖²
            |M|
```

`|M| = rN`으로 정규화.

### 5.1 왜 "가려진 패치만"인가? (유도)

전체 패치에 대한 손실을 쓰면:

```
           1  ⎡                         ⎤
  L_all = ─── ⎢ Σ_{i∈S}‖x̂_i−x_i‖²  +  Σ_{i∈M}‖x̂_i−x_i‖² ⎥
           N  ⎣   (A): 자명한 항              (B): 진짜 항   ⎦
```

**(A)가 문제다.** 디코더는 보이는 패치를 입력으로 이미 갖고 있으므로, 출력에서 그대로 흘려보내면(identity) `x̂_i ≈ x_i`가 되어 `(A) → 0`. 즉 (A)는 **공짜(trivial)**이며, 전체 손실은:

```
  L_all ≈ (rN/N) · L_masked = r · L_masked      (근사적으로 상수배)
```

상수배는 gradient 방향을 바꾸지 않는다. 그런데 왜 굳이 마스킹만 쓰나?

1. **수치적 안정/집중:** 공짜 항을 계산·정규화에서 빼면 모든 gradient가 의미 있는 항 (B)에만 집중된다.
2. **치팅 방지:** 디코더가 identity를 학습하도록 유도하는 손실 성분을 애초에 없앤다(가려진 패치엔 identity가 불가하므로).
3. **스케일 일관성:** 정규화가 `1/rN`이 되어 `r`을 바꿔도 손실 스케일이 비교 가능.

> 요약: `L_masked`가 최적화의 "실질 신호"이고, `L_all`은 그 신호에 상수를 곱하고 공짜 항을 더한 것뿐이라 이득이 없다.

### 5.2 왜 MSE(회귀)? 그리고 왜 정규화된 픽셀?

- 복원 대상은 연속 픽셀 → 회귀 → MSE가 자연스럽다.
- MAE는 픽셀을 **패치별 평균·분산으로 정규화**해 MSE를 계산 → 고주파(노이즈) 성분에 덜 민감, 표현 품질↑.

## 6. 비대칭 구조의 계산량 분석

어텐션 비용은 시퀀스 길이의 **제곱**에 비례한다. (self-attention: `O(L² d)`)

**인코더 측:**
```
일반(마스크 토큰 포함, 대칭):   O( N² D )
MAE(보이는 패치만):            O( ((1-r)N)² D )
                              ────────────────── = (1-r)²
                                      N²
```
`r = 0.75` → `(0.25)² = 1/16`. 인코더 어텐션 FLOPs가 **16배** 감소.

**메모리:** 어텐션 행렬 크기 `O(L²)` → `((1-r)N)² = N²/16`. 활성값 메모리도 대폭 절감.

**디코더 측:** 전체 `N` 토큰을 쓰지만 **가볍다**(예: `D'=512`, 8 블록, 그리고 무엇보다 **학습 후 폐기**).

**총합:** 인코더가 지배적일 때, 학습 속도 **약 3배 이상** 향상 (+ 정확도도 향상). 이론적 `(1-r)²`만으로는 16배지만, 실제 ViT는 MLP/FFN 등 선형항이 있어 전체로는 3배 수준.

---

## 7. 왜 75%인가? — 정보 밀도(information density)

**언어 vs 이미지:**

언어 토큰은 정보 밀도가 높다(각 단어가 대부분의 의미를 담음). 그래서 BERT는 **15%**만 가려도 어렵다. 이미지는 인접 패치 간 **상관이 매우 크다**(공간적 중복). 몇 %만 가려도 이웃에서 복원 가능 → 과제가 너무 쉽다.

이를 조건부 엔트로피로 표현하면, 어떤 패치 `x_i`의 이웃 `x_{∂i}`가 주어졌을 때:

- 이미지에서 `H(x_i | x_{∂i})`가 **작다** (예측 쉬움) → 조금만 가리면 정보가 남아 과제가 자명해짐.
- 따라서 **매우 많이 마스킹**해야 조건부 불확실성을 충분히 키워 "전체 구조 이해"를 강제할 수 있다.

**재구성-표현 연결 (직관적 유도):**

가려진 패치의 최적 예측자는 조건부 평균이다:
```
  x̂_i* = E[ x_i | x_S ]
```
이 값은 **결합분포 p(x_S, x_i)**를 알아야 계산된다. 즉 손실을 줄이려면 데이터의 **결합 구조(엣지·텍스처·객체·장면)**를 내재화해야 한다. `r`이 클수록 저수준 보간(nearest-neighbor)으로는 `E[x_i|x_S]`에 도달 불가 → **고수준 의미 모델링**이 강제된다.

이것이 "저수준 픽셀 복원 → 고수준 표현"이 성립하는 수학적 이유다.

## 8. 요약

| 항목 | 수식/결과 |
|---|---|
| 마스킹 | 선택 행렬 `P_S` |
| 인코더 | `H = f_enc(Z_S)`, 보이는 패치만 |
| 디코더 | `Y = g_dec(Unshuffle([proj(H); m]))` |
| 손실 | `L = (1/rN) Σ_{i∈M}‖x̂_i − x_i‖²` |
| 속도 | 인코더 어텐션 `∝ (1-r)²` → 75%에서 1/16 |
| 난이도 | 조건부 엔트로피 키우기 위해 `r`↑ |
| 표현 | `x̂→E[x_i|x_S]` 학습 ⇒ 결합분포 학습 |

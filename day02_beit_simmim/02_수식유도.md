# 02. 수식 유도 — 두 목적함수(CE vs ℓ1)와 dVAE 2단계 우도

> BEiT(2106.08254)와 SimMIM(2111.09886)의 목적함수를 수식으로 분해하고, "이산 타깃 vs 연속 타깃"의 의미를 비교한다.

---

## 0. 표기(Notation)

| 기호 | 의미 |
|---|---|
| `x ∈ R^{H×W×C}` | 입력 이미지 |
| `x_i` | i번째 패치(펼친 벡터), `i∈{1..N}` |
| `z = (z_1..z_N)` | **이산** 시각 토큰(코드북 `V`, `|V|=8192`) |
| `M` | **가려진** 패치 인덱스 집합 |
| `x_M` | 마스킹된(손상된) 이미지 |
| `p_θ(·)` | 인코더(파라미터 θ)가 만든 예측분포 |
| `y_i` | 예측 픽셀, `Ω(·)` | 원소 수 |

## PART A. BEiT — 잠재변수 우도와 2단계

### A.1 출발점: 잠재변수 모델

이미지가 **이산 잠재변수 z**(시각 토큰)를 통해 생성된다고 본다:

```
p(x, z) = p(z) · p(x | z)
```

데이터 로그우도는 z를 적분(주변화)한 것:

```
log p(x) = log Σ_z p(x | z) p(z)
```

`z`가 고차원 이산이라 직접 계산 불가 → 변분 하한(ELBO)으로 분해:

```
log p(x)  ≥  E_{q(z|x)}[ log p(x | z) ]  −  KL( q(z|x) ‖ p(z) )
              └─────── (I) 복원 항 ───────┘     └── (II) 정규화 ──┘
```

여기서 `q(z|x)`가 **이미지 토크나이저(인코더)**, `p(x|z)`가 **디코더**다.

### A.2 2단계 = 두 항을 분리 최적화

BEiT(및 DALL-E)는 (I)·(II)를 **동시에** 풀지 않고 **두 단계로 분리**한다:

```
[Stage 1 · dVAE]   max_φ  Σ_x  E_{q_φ(z|x)}[ log p_ψ(x | z) ]           (복원, 토크나이저)
[Stage 2 · MIM ]   max_θ  Σ_x  E_{M} [ Σ_{i∈M} log p_θ(z_i | x_M) ]     (토큰 예측, 인코더)
```

논문의 식 (3)은 이 둘을 합친 형태로, **두 번째 항이 BEiT의 사전학습 목적**임을 명시한다:

```
log p(x)  ≈  log p(x | ẑ)   +   log p_θ( ẑ | x̃ )
             └ Stage 1 (dVAE) ┘   └ Stage 2 (BEiT MIM) ┘
```

- **Stage 1**은 `z`를 "만드는" 단계(토크나이저). `ẑ = argmax_z q(z|x)`.
- **Stage 2**는 만들어진 `z`를 **정답 라벨로 고정**하고 `p_θ(z|x)`를 학습.
- **왜 2단계가 강제되나?** `z`가 이산이라 `p(x|z)`·`q(z|x)`가 미분 불가(Gumbel/straight-through 필요)하고, 토크나이저와 인코더를 함께 학습하면 **안정성이 나쁘다**. 그래서 "토크나이저 먼저 → 고정 → 인코더"로 분리한다.

### A.3 Stage 2 목적함수 (논문 식 (1))

```
max_{x∈D}   E_{M} [ Σ_{i∈M}  log p_MIM( z_i | x_M ) ]
```

- `E_M`: 마스킹 위치 `M`에 대한 기대값(`M`을 무작위로 뽑음).
- **가린 위치에서만** 정답 토큰의 로그확률을 최대화(가린 건 못 봄).

예측분포는 MIM head의 softmax 분류:

```
p_MIM(z_i | x_M) = softmax( W h_i + b ) ,    h_i = [f_θ(x_M)]_i ∈ R^D
```

`h_i`는 인코더가 i번째(마스킹된) 위치에 대해 낸 은닉 벡터다. 손실은 **교차엔트로피**:

```
L_BEiT = − (1/|M|) Σ_{i∈M}  log [ softmax(W h_i + b) ]_{z_i}
```

> 핵심: 타깃이 **연속 벡터가 아니라 클래스 인덱스 `z_i`** 이므로 회귀(MSE)가 아닌 **분류(CE)** 다.

### A.4 왜 "이산 토큰"이 의미를 담나

dVAE는 `z`가 **저주파 의미 구조**를 담도록 압축·양자화한다. 따라서 `z_i`를 맞히려면 모델이 **고주파 픽셀 디테일이 아니라 시각적 의미**를 모델링해야 한다.
- 반대로 **픽셀 직접 복원**은 "단거리 의존·고주파 디테일"에 집중하게 만든다(논문의 지적).
- 대조: `− Visual tokens (recover masked pixels)` 로 바꾸면 ImageNet 82.86 → **81.04**, ADE20K 44.65 → **41.38** 로 하락(절제실험 Table 4).

## PART B. SimMIM — 연속 픽셀 회귀와 ℓ1

### B.1 목적함수 (논문 식 (1))

가린 픽셀에서만 원시 RGB에 대한 ℓ1 손실:

```
L_SimMIM = 1/Ω(x_M) · ‖ y_M − x_M ‖_1
```

- `x, y ∈ R^{3HW×1}`: 입력 RGB와 예측 RGB, `M`: 가린 픽셀 집합, `Ω(·)`: 원소 수.
- 정규화 `1/Ω(x_M)` = **가린 픽셀 수**로 나눔(마스킹 비율과 무관하게 스케일 일관).
- 기본 **ℓ1**. 실험에서 **ℓ2, smooth-ℓ1과 유사**한 성능, 저자들은 ℓ1 채택.

### B.2 왜 ℓ1이고, 왜 원시 픽셀인가

- `y`가 연속 픽셀 → **회귀**가 자연스럽다. 목적: `E[x_i | x_visible]`(조건부 평균) 근사.
- **ℓ1 vs ℓ2**: ℓ1의 최적해는 **조건부 중앙값**(median), ℓ2는 **조건부 평균**. 픽셀 복원은 다봉(multi-modal) 분포(모서리·텍스처)라 **median이 이상치·고주파에 덜 휘둘림** → ℓ1이 안정적. (실측으론 셋이 비슷.)
- **원시 픽셀이 이산 토큰을 이긴다**: 절제에서 `target=raw pixel`이 복잡한 patch-classification(토큰) 설계보다 **나쁘지 않거나 우수**. 즉 **토크나이저 없이도** 강력 → 파이프라인 단순.

### B.3 학습이 "표현"을 만드는 이유 (직관적 유도)

가린 패치의 최적 예측자는 조건부 기대값:

```
x̂_i* = E[ x_i | x_visible ]
```

이를 계산하려면 데이터 결합분포 `p(x_visible, x_i)`— 즉 **객체·텍스처·맥락 구조**— 를 내재화해야 한다. 마스크 **패치가 크면(32)** 가린 영역 주변에 보이는 이웃이 안 남아, 저수준 보간으로는 도달 불가 → **고수준 모델링 강제**.

### B.4 AvgDist — 마스킹 난이도의 정량 지표

SimMIM이 제안한 지표: 가린 픽셀에서 **가장 가까운 보이는 픽셀까지의 평균 유클리드 거리**.

- **AvgDist ↑ ⇒ 과제 어려움 ↑** (힌트가 멀다).
- 큰 마스크 패치(32) + 적당한 비율(60%)이 적절한 AvgDist를 만든다.
- 작은 패치(8)는 AvgDist가 작아 **비율을 80%까지** 높여야 경쟁력 → 즉 **마스크 패치 크기와 비율이 함께** 난이도를 결정.

## PART C. 두 목적함수 비교 (정보이론 관점)

| 관점 | **BEiT (CE, 이산)** | **SimMIM (ℓ1, 연속)** |
|---|---|---|
| 타깃 | 클래스 `z_i ∈ V` | 벡터 `x_i ∈ R^{P²C}` |
| 목적 | `max log p(z_i\u007cx)` | `min ‖y−x‖₁` |
| 최적해 | **클래스 사후확률** | **조건부 중앙값** |
| 난이도 | 의미 구별(의미 지향) | 픽셀 근사(저수준~구조) |
| 추가 모듈 | **dVAE 토크나이저 필요** | **불필요** |
| 손실 성질 | 확률분포 매칭 | robust 회귀 |

**요약:** 둘 다 "가린 것을 조건부로 예측"한다. 차이는 **타깃의 표현형(이산/연속)** 이며, 이것이 **분류냐 회귀냐**, **토크나이저가 필요하냐**, **의미 지향이냐 저수준이냐** 를 갈라놓는다.

## 2. 코드에서 확인할 3가지 (MAE와의 대비)

| # | SimMIM 코드 | 대응 (MAE 데모) | 의미 |
|---|---|---|---|
| ① | `z = torch.where(mask, mask_token, z)` → **전체를 인코더에** | 마스크 위치 **제거** 후 보이는 것만 인코딩 | 마스크 토큰을 **인코더가 본다** |
| ② | `self.head = nn.Linear(dim, patch*patch*3)` (단일 선형) | **비대칭 디코더**(여러 층) | **경량 head** = 표현 부담이 인코더로 |
| ③ | `loss = (pred[mask]-target[mask]).abs().mean()` (**ℓ1**) | `mse(pred, target)` (**ℓ2**) | 타깃=원시 픽셀, 손실=ℓ1 |

핵심 한 줄:
```python
# SimMIM: 마스크 "대체(replace)" — 인코더가 마스크 토큰을 처리
z = torch.where(mask.unsqueeze(-1), self.mask_token.expand_as(z), z)
```

## 3. 실습 과제 (직접 실행해보세요)

**과제 A — 마스킹 비율 스윕.** `--mask-ratio`를 `0.3 / 0.5 / 0.6 / 0.75 / 0.9`로 바꿔 최종 ℓ1을 기록하라.
- 질문: 비율이 너무 낮으면/높으면 ℓ1이 어떻게 되나? 왜 논문 기본이 0.6인가?

**과제 B — 마스크 패치 크기.** `--mask-patch`를 `1`(랜덤 패치)과 `2`(블록)로 비교하라.
- 질문: 같은 비율에서 **블록**이 더 어려운가(AvgDist ↑)? ℓ1이 더 높게 나오는가?

**과제 C — head 깊이.** `SimMIM.head`를 2~3층 MLP로 바꿔보라. 논문 주장("as light as a linear layer")과 일치하나?

**과제 D (사고) — SimMIM을 BEiT로 바꾸려면?** 아래를 글로 설명하라.
- `head`를 `nn.Linear(dim, 8192)` 분류기로, 손실을 `cross_entropy`로.
- 타깃을 **dVAE 토큰 ID**로 바꿔야 함 → **토크나이저(dVAE)가 추가로 필요**.
- 즉 BEiT = "SimMIM의 픽셀 타깃을 **이산 토큰 + CE**로 치환하고 토크나이저를 붙인 것".

**과제 E (선택) — AvgDist 계산.** 마스크된 각 픽셀에서 가장 가까운 보이는 픽셀까지 평균 거리를 계산해 `--mask-patch`별로 비교하라(= 논문 지표 재현).

## 4. 체크리스트

- [ ] 데모가 **에러 없이** 실행되고 ℓ1이 감소했다.
- [ ] 마스크 토큰을 인코더에 **넣는** 코드(`torch.where`)를 찾아 표시했다.
- [ ] head가 **단일 선형층**임을 확인했다.
- [ ] 손실이 **ℓ1**이며 **가린 픽셀에서만** 계산됨을 확인했다.
- [ ] 과제 A/B 중 최소 1개를 실행하고 결과를 기록했다.
- [ ] BEiT와의 차이를 **"타깃(이산 토큰) + 손실(CE) + 토크나이저"** 로 한 문장에 설명할 수 있다.

---

## 5. 참고: BEiT는 왜 이 데모에서 재현하지 않나

BEiT 재현에는 **dVAE 토크나이저**(DALL-E, 코드북 8192)의 사전학습/가중치가 필요하다(2단계). 합성 데이터·소규모로는 토크나이저 학습이 무의미하므로, 이 실습은 **토크나이저가 불필요한 SimMIM**으로 MIM의 공통 골격(마스킹→인코더→예측→가린 곳 손실)을 체득하고, BEiT는 **과제 D**로 개념만 연결한다.

# 04. 비교표 — Attention 변형(MHA/MQA/GQA/MLA) & FFN(MoE) 한눈에

> 기준: DeepSeek-V2 (arXiv:2405.04434) · V2 설정 `n_h=128, d_h=128, d_c=512, d_c'=1536, d_h^R=64, l=60`

---

## 1. Attention 변형 — KV cache vs 표현력

| 방식 | KV cache / token / layer | V2 설정(×l=60) | KV 헤드 | 표현력 | 비고 |
|---|---|---|---|---|---|
| **MHA** | `2·n_h·d_h` = 32,768 | 1,966,080 | n_h | 기준(최고) | cache 폭발 |
| **MQA** | `2·d_h` = 256 | 15,360 | 1 | 낮음 | 과압축 |
| **GQA** (g group) | `2·n_g·d_h` | `n_g`에 비례 | n_g | 중간 | 헤드 묶음 손실 |
| **MLA** | `(d_c + d_h^R)` = 576 | **34,560** | — (잠재) | **MHA 이상** | 저랭크+흡수 |

- **MQA/GQA**: KV 헤드를 **묶어서** cache를 줄임 → **표현력 손실**.
- **MLA**: KV를 **저랭크 공통공간**으로 압축 → cache를 줄이면서 **헤드별 표현력 유지**(실측 MHA보다 우수).
- V2 설정 MHA 대비 MLA cache 감소: `1 − 34560/1966080 = 98.24%`.

### 1.1 MLA vs GQA 핵심 차이

| | GQA | MLA |
|---|---|---|
| 축소 방식 | KV **헤드 공유** | KV **저랭크 압축** |
| 추론 시 K/V | 그래도 계산 | **흡수로 미계산** |
| 위치(RoPE) | 그대로 | **decoupled** |
| 표현력 | ↓ | **↑** |

## 3. FFN — Dense vs MoE vs DeepSeekMoE

| | Dense FFN | 일반 MoE | **DeepSeekMoE** |
|---|---|---|---|
| 활성 파라미터 | 전체 | 일부 전문가 | 일부 + 공유 |
| 전문가 세분화 | — | 보통 | **fine-grained** |
| 공유 전문가 | — | 없음 | **N_s=2** |
| 지식 중복 | — | 큼 | **↓(공유가 담당)** |
| V2 | — | — | **236B / 21B 활성** |

- **조합 폭발**: 전문가를 `m`배 쪼개고 활성도 `m`배 → `C(N,K)` 급증 → 표현력↑ (같은 활성 파라미터).
- **공유 전문가**가 공통지식을 전담 → 라우팅 전문가 전문화.

## 6. 한 문장 정리

> **MLA는 "KV를 저랭크로 접고, 업프로젝션을 흡수하고, RoPE만 소채널로 뺀다"** — cache·연산을 줄이면서 표현력은 올린다.
> **DeepSeekMoE는 "잘게 쪼개고 일부를 공유"** — 236B를 21B 활성으로 돌린다.

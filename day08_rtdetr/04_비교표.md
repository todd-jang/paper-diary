# 04 · 비교표 — RT-DETR 논문 수치 총정리 (+ DETR·YOLO 대비)

> 원칙(README): **같은 시스템·도메인 안에서 변수 하나만 바꿀 때만** ablation이 성립. 서로 다른 논문·다른 입력 크기·다른 하드웨어의 숫자를 한 표에서 우열로 읽지 않는다. 아래 §6에 **같이 놓으면 안 되는 것**을 명시했다.

## 6. 같이 놓으면 안 되는 것 (경계)

| 비교 | 왜 같은 줄이 아닌가 |
|---|---|
| RT-DETR 53.1 AP(640×640·72ep) vs DETR-DC5 43.3 AP(800×1333·500ep) | 입력 크기·스케줄·백본 변형이 모두 다르다. "RT-DETR가 정확하다"가 아니라 **"같은 실시간 예산(108 FPS) 안에서 YOLO를 이긴다"**로 읽을 것 |
| RT-DETR의 FPS 108 vs YOLO의 54~99 | 조건이 다르면(엔드투엔드 벤치마크·T4·FP16) YOLO가 NMS 시간을 빼고 측정했을 수 있다 — RT-DETR §3.2가 정확히 이 지점을 문제 삼는다 |
| DETR 42.0(500ep) vs DETR 40.6(300ep) | 같은 시스템 안의 스케줄 변수 → 성립. 차이는 학습 길이 |
| Table 3의 지연(1× 설정) vs Table 2의 FPS(6× 설정) | **학습 스케줄·입력 크기가 다르다.** Table 3은 ablation용 1×, Table 2는 최종 6×(72ep) |
| 49% GFLOPs / 11% AP | RT-DETR가 **Lin et al. 2022를 인용한 2차 통계**이며 RT-DETR 자신의 측정값이 아니다 |
| 실습 [A]~[D] 수치 vs 논문 수치 | 실습은 **합성 데이터·미니 구현·학습 없음**이라 방향·순서만 비교 가능. AP·지연 절대값은 비교 대상 아님 |

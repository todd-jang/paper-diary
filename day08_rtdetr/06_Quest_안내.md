## Q1. NMS를 지우면 무엇을 얻고 무엇을 잃는가

**(a)** §3.1·Table 1의 두 방향을 **수치로**: conf 0.001→0.05→(0.25)에서 NMS 시간 2.36→1.73→1.06ms와 AP 52.9→52.4→51.2, IoU 0.5→0.6→0.8에서 2.24→2.29→2.46ms와 AP 52.1→52.6→52.8. 왜 이 딜emma가 NMS-free로 풀리는지 설명하라.
**(b)** §3.2의 end-to-end speed benchmark가 왜 필요한지 — YOLO가 보통 **NMS 시간을 제외한 모델 속도만** 보고한다는 점과, anchor-based가 anchor-free보다 박스를 **3배** 많이 낸다는 점을 포함해라.
**(c)** NMS-free의 **대가**가 존재한다면 어디인가 — ~~논문이 언급한 **Video Object Detection(레이블 있는 프레임 IoU)** 관점의 문단을 찾아 답하라.~~
> **⚠️ 2026-10-21 교정(선생님)**: 이 질문의 **전제가 틀렸습니다.** RT-DETR 원문에는 "Video Object Detection"이 **한 번도 없고**(video는 응용례 언급 2회뿐), 프레임 IoU 분석도 없습니다. **"이 논문이 Video OD를 분석했다"는 귀속은 성립하지 않으며, 원문으로 확인해 지적한 학생이 정답입니다.** 올바른 질문은 "NMS-free라는 **구조**가 가져오는 대가는 무엇인가"(문헌 분석이 아닌 구조적 추론)입니다.
**(d)** 실습 [A] 실측(conf 0.001 → 0.25: 시간 57.03 → 21.29ms, AP proxy 1.000 → 0.933 / IoU 0.5 → 0.8: 43.05 → 59.95ms, 0.967 → 1.000)이 논문과 **방향은 같은지**, **절대값이 다른 이유**는 무엇인지(하드웨어·구현·지표의 차이) 설명하라.

## Q2. AIFI는 왜 S5에만 붙는가

**(a)** 인코더 병목 진단(**49% GFLOPs vs 11% AP**)을 인용하고, 이 수치가 **RT-DETR 자신의 측정이 아니라 인용(2차 통계)**이라는 점을 명시하라.
**(b)** Table 3의 A(43.0/7.2ms) → B(44.9/11.1) → C(45.6/13.3) → D(46.4/12.2) → D_S5(46.8/7.9) → E(47.9/9.3)을 순서대로 읽어 **D(분리)**와 **D_S5(S5 한정)**가 각각 무엇을 증명하는지 나눠서 답하라.
**(c)** 논문의 하위 레벨 기각 사유(논문 인용: 의미 개념 부족 + *"the risk of duplication and confusion with high-level feature interactions"*)를 인용하고, attention 비용이 **$M^2$**이라는 계산을 붙여 "왜 의미가 모인 레벨을 택했는지" 연결하라.
**(d)** 실습 [B](400 → 3200 토큰 = 시간 42.3배, 이론 64배 / 8400 vs 400 = 441배 토큰 차 / 1×1 conv 2.24ms)와 실습 [C]의 **지연 순서가 논문과 완전 일치**(A < D_S5 < E < B < D < C)한 결과를 근거로 인용해, 이 선택이 뒷받침되는 방식을 서술하라.

## Q3. uncertainty는 무엇을 바꾸는가

**(a)** 식 (2) $U=\|\mathcal P(\hat{\mathcal X})-\mathcal C(\hat{\mathcal X})\|$가 **분류 예측 분포와 위치 예측 분포의 불일치**를 담는다는 점, 식 (3)이 이를 **손실에 넣는다**는 것이 무엇을 뜻하는지(인코더가 두 관측을 일치시키게 학습된다) 설명하라.
**(b)** Table 4(AP 47.9 → 48.7, Prop cls 0.35% → 0.82%, Prop both 0.30% → 0.67%)와 Fig 6(보라가 **우상단** 집중, 밀도 차 **138%**·**120%**)을 인용하라. 이 두 퍼센트가 **"퍼센트포인트 향상"이 아니라 "상대 개수 차"**인 이유를 논문 문장 구조로 확인해 답하라.
**(c)** **선택과 최적화를 분리**하라 — 공개 코드의 `torch.topk(enc_outputs_class.max(-1).values, 300)`(`rtdetr_decoder.py:491`)이 무엇을 기준으로 하는지 인용하고, 그러면 이 기도는 정확히 **무엇을** 바꾼 것인가(랭킹이 아니라 손실 쪽) + Table 4·Fig 6은 그 효과의 어떤 증거인가.
**(d)** 실습 [D]의 **퇴화 해**(U만 단독 최적화 → s 0.90 → 0.690, q 0.20 → 0.693으로 **만나는 지점**에 수렴; 분류 손실 병행 시 s 0.794 · q 0.793으로 품질이 확신을 따라감)를 설명하고, RT-DETR은 이 퇴화를 **어떻게** 피하는지(식 3의 구성) 답하라. 그리고 1차원 프록시로 만든 ablation이 이 점검을 **반드시** 해야 하는 이유를 Day 07 실습 [D]의 관측(Prop cls 1.000 → 0.127)과 연결해라.

## Q4. 깊이 하나로 속도를 바꾸는 법

**(a)** Table 5의 Det 6 열(6층 53.1/9.3ms · 5층 53.0/8.8ms · 4층 52.7/8.3ms · 1층 49.1/7.0ms)에서 **층당 비용은 거의 일정(0.4~0.5ms)인데 정확도 이득은 층이 올라갈수록 줄어든다(+2.2 → +0.1)**는 구조를 읽어라.
**(b)** **재학습 없이** 가능한 **구조적 이유**(aux decoding loss가 모든 디코더 층의 출력을 학습시킨다 — 원문 DETR §3.2)를 인용해 설명하라.
**(c)** 이 구조가 **배포**에서 어떤 결정을 허용하는지 — `eval_idx`(어느 층 출력 사용)와 05_실전 가이드의 **`max_det`(ONNX/TensorRT export 시 출력 개수 제한)**를 인용해 답하라.
**(d)** 경계: Day 07 미니 데모는 **반대 방향**(uncertainty 런 5층 0.802 > 6층 0.791)을 보였다. 왜 그런지(합성 데이터·쿼리 30개 vs 실객체 1~4개·층별 독립 supervision) 설명하고, 이 차이를 **어떤 범위에서만** 일반화할 수 있는지 답하라.

## Q5. 정확도↑ + 속도↑는 왜 가능한가, 무엇을 감수해야 하는가

**(a)** RT-DETR-R50(53.1 AP/108 FPS)과 DETR(42.0 AP/28 FPS)의 비교를 **입력 크기(640×640 vs 800×1333)·스케줄(72ep vs 500ep)·하드웨어(T4·TensorRT FP16·bs=1)·YOLO의 NMS 포함 벤치마크** 조건을 모두 밝혀 서술하라 — 절대 비교가 아니라 **조건부 비교**로.
**(b)** 세 손잡이(**NMS 제거 · 하이브리드 인코더 · uncertainty 쿼리 + aux 헤드**)가 각각 **어떤 비용을 어떤 구조로 지불**하는지 한 문단으로 정리하라(무엇을 포기하고 무엇을 얻었는지).
**(c)** 감수하는 것 — **AP_S 34.8(YOLOv8-L 35.3보다 −0.5), R101은 36.0 vs YOLOv7-X 36.9(−0.9)** — 을 인용하고, 왜 남는가(멀티스케일 특징을 쓰면서 실시간성을 위해 attention을 제한한 설계) 그리고 후속 해가 어디인가(**Deformable 계열은 예비로 이동했으므로 3D 트랙(BEV·멀티뷰)과의 연결** — 를 답하라. 3D 지도의 DETR3D가 "3D 기준점을 카메라 평면에 투영"하는 방식을 한 단어로 언급하라.
**(d)** 마지막: 이 논문에서 **배우지 못한 것**을 **최소 2개** 찾아라. 후보: ① 49/11은 2차 통계 ② NMS-free는 Video OD(레이블 있는 프레임 IoU)에서 불리할 수 있음 ③ FPS는 특정 하드웨어·정밀도·입력에 종속 ④ 2D 전용(3D 확장 불가) ⑤ uncertainty의 배포 구현이 공개 v1 코드와 불일치(랭킹은 cls 점수) ⑥ query selection의 위치 품질 proxy(anchor IoU) 한계.

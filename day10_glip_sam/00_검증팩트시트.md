## 1. GLIP — Grounded Language-Image Pre-training

### 1.0 신원
- **발표**: CVPR 2022, pp.10965–10975 (oral, Best Paper Finalist)
- **arXiv**: [2112.03857](https://arxiv.org/abs/2112.03857)
- **저자**: Liunian Harold Li*, Pengchuan Zhang*, Haotian Zhang*, Jianwei Yang, Chunyuan Li, Yiwu Zhong, Lijuan Wang, Lu Yuan, Lei Zhang, Jenq-Neng Hwang, Kai-Wei Chang, Jianfeng Gao (*동등 기여)
- **소속**: UCLA · MSR · UW · UW–Madison · Microsoft Cloud·AI · IDEA
- **공식 레포**: [microsoft/GLIP](https://github.com/microsoft/GLIP) (라이브, 리네임 없음, 최근 push 2024-01-24)
- **체크포인트 호스트 이동**: Azure 원링크 만료 → HuggingFace `GLIPModel/GLIP` (README)

### 1.1 기구 (검증 인용 + 섹션 번호)

**(a) 탐지를 phrase grounding으로 통합 — 목적함수 정신**
> §3.1: *"Any object detection model can be converted to a grounding model by replacing the object classification logits in its box classifier with the word-region alignment scores, i.e., dot product of the region (or box) visual features and the token (or phrase) language features."* (Eq. 2–3: 분류 가중치 W → 프롬프트 피처 P = Enc_L(Prompt); 로짓 S_ground = O P^T. 그외 손실 구조는 그대로)

- 토큰 수준 정답 확장(§3.1): phrase 정답 T → sub-word 레벨 T' (긍정 phrase의 모든 sub-word = 긍정; 추가 토큰·[NoObj] = 부정). 추론: "we average token probabilities as the phrase probability".
- 분등가 주장(§3.1/App. §B): 같은 DyHead·Swin-Tiny 변형에서 reformulate 전/후 **COCO val2017 둘 다 49.4 AP**.

**(b) 프롬프트 양식**
> §3.1: *"Prompt = "Detect: person, bicycle, car, ..., toothbrush"" (클래스 이름 = grounding 후보 phrase)
> 경험칙(§3.1): BERT 초기화 사용 시 `"person. bicycle. car. ..."` 식 **온점 나열 프롬프트**가 더 잘 작동
- 레포 설정(`configs/pretrain/glip_Swin_T_O365_GoldG.yaml`): 분리자 `". "` · 프롬프트 카테고리 **85개** 샘플링(App. §C.1) · 프롬프트 입력 최대 **256 토큰** · LVIS zero-shot은 40개/프롬프트 청크(App. §C.2)

**(c) 언어 경유 딥 퓨전**
- 언어 인코더 = **BERT(base-uncased)** (App. §B; 설정 `LANGUAGE_BACKBONE.MODEL_TYPE`), 이미지 = **Swin Transformer + Dynamic Head(DyHead)** (§2)
> §3.2 (Eq. 4–6): 각 레이어에서 `O^{t2i}_i, P^{i2t}_i = X-MHA(O_i, P_i)` → `O_{i+1} = DyHeadModule(O_i + O^{t2i}_i)`, `P_{i+1} = BERTLayer(P_i + P^{i2t}_i)` ("*BERTLayer is newly-added BERT Layers on top of the pre-trained BERT*")
- 즉 **모든 DyHead 레이어에 단어 피처 O^{t2i}가 여분 문맥벡터로 여입** — 없으면 late-fusion으로 퇴화(§3.2). 레포 설정: `EARLY_FUSE_ON: True` · `TYPE: "MHA-B"` · `USE_DOT_PRODUCT_TOKEN_LOSS: True`

**(d) NMS / 쿼리 선택**
- 본문(§4.1): SoTA 달성에 "soft-NMS 같은 bells and whistles 미사용" — 즉 **soft-NMS 부재**
- 레포 기본값(`defaults.py`): `ROI_HEADS.NMS=0.5` · `RETINANET.NMS_TH=0.4` · `CAPTION_NMS=0.9` · DETECTIONS_PER_IMG 300(README eval)
- 쿼리: `DYHEAD.TOPK=9` 후보 선택 · 토큰확률 평균 `SCORE_AGG: "MEAN"`

**(e) 사전학습 데이터 규모/조합** — 초록 + §3.3 + Table 1

- 초록: **27M grounding data = 3M 사람 검수 + 24M 웹 이미지-텍스트**. §3.3: 24M 쌍에서 **78.1M 고품질(>0.5) phrase-box 가짜정답, 58.4M 고유 명** — 검출 데이터(category ≤2,000) 대비 phrase scale이 지배(Flickr30K 44,518 · VG Caption 110,689 고유 phrase)
- 내성 구성(App. §C.1): Swin-T **GPU 32장** / Swin-L **GPU 64장**, batch 64, lr 1e-4(언어경유 1e-5), step decay ×0.1 @67%/89%
- 검증 조건(레포 설정 — 논문에 없음): `MIN_SIZE_TEST 800 / MAX_SIZE_TEST 1333`; 학습 `MULT_MIN_SIZE_TRAIN (480~800)`

## 2. SAM — Segment Anything

### 2.0 신원
- **발표**: ICCV 2023, pp.4015–4026 (⚠ abs comment에 venue 미기재 — CVF Open Access만 근거)
- **arXiv**: [2304.02643](https://arxiv.org/abs/2304.02643) (v1만 존재)
- **저자**: Alexander Kirillov, Eric Mintun, Nikhila Ravi, Hanzi Mao, Chloe Rolland, Laura Gustafson, Tete Xiao, Spencer Whitehead, Alexander C. Berg, Wan-Yen Lo, Piotr Dollár, Ross Girshick — **Meta AI Research, FAIR**
- **공식 레포**: [facebookresearch/segment-anything](https://github.com/facebookresearch/segment-anything) (라이브, 리네임 없음; README 톱에 **SAM 2** 소개, arXiv 2408.00714)
- 라이선스: Apache 2.0(모델) / SA-1B 별도 리서치 라이선스

### 2.1 기구 (검증 인용 + 섹션 번호)

**(a) 프롬프팅터블 분할 과제 정의(§2)**
> *"the promptable segmentation task, then, is to return a valid segmentation mask given any prompt. The requirement of a 'valid' mask simply means that even when a prompt is ambiguous ..., the output should be a reasonable mask for at least one of those objects."*
- 프롬프트 유형: 전경/배경 점·사각box·마스크·**자유문장 텍스트** (CLIP 오프셀프 텍스트 인코더)

**(b) 3요소 구성(§3 + App. §A)**
- **이미지 인코더**: *"MAE pre-trained **ViT-H/16 with 14×14 windowed attention and four equally-spaced global attention blocks***", 입력 **1024×1024**(shorter side padding), 임베딩 **64×64** → 1×1 conv 256ch → 3×3 conv 256ch
- **프롬프트 인코더**: 점/box는 위치인코딩+타입 임베딩(256d) — 텍스트는 **CLIP 텍스트 인코더**; dense(마스크) 프롬프트는 conv 체인(4→16→256ch)
- **마스크 디코더**: *"a modification of a Transformer decoder block"* — **2층 블록**, dim 256, MLP 2048, **8 heads**, 셀브/카살 어텐션 양방향, 상향샘플(4× 전치 conv) 후 MLP 출력 토큰이 **동적 선형 분류기**(마스크를 매 점 생성)

**(c) 애매성 처리(§3 + §A)**
- **출력 마스크 3개** — 마스크: "whole, part, subpart" 중첩 단계 기준
- 학습: *"we compute the loss ... between the ground truth and each of the predicted masks, but only **backpropagate from the lowest loss**"*; 마스크 랭킹은 **estimated IoU** 토큰
- **다중 프롬프트 예외(§A, 중요)**: *"we only predict a single mask when more than one prompt is given... This fourth mask is never returned for a single prompt and is the only mask returned for multiple prompts."* — 즉 **"항상 3개"는 아님**
- 손실: **focal:dice = 20:1** + IoU 두 MSE(scale 1.0); 학습 커리큘럼 = 8차 이터레이션(초기 1프롬프트 + 8 반복 점 + 재파인 2회)

**(d) SA-1B (§4 데이터 엔진 3단계 + §5)**
- **11M 이미지 / 1129M(1.1B) 마스크**(Fig. 6) — 평균 이미지 해상도 3300×4950, 공개본 shortest side 1500px
- 단계 1 보조-수동: 120k 이미지 → **4.3M 마스크**, 마스크/이미지 20→44, 시간/마스크 34s→14s, 인코더 ViT-B→ViT-H 재학습 6회
- 단계 2 반자동(박스디텍터 사전채움): +180k 이미지 → 누적 **10.2M**, 마스크/이미지 44→72, 재학습 5회
- 단계 3 자동: **32×32 규칙 점 그리드**(전체 이미지 + 20개 확대 crop) → **1.1B 마스크**, 평균 ~100 마스크/이미지
- 품질 필터(§B): 예측 IoU **88.0** 이하 제거 · 안정성 IoU **95.0** · 전체 특정 마스크(≥95% 면적) 제거 · **box NMS 0.7** · 미니 컴포넌트 <100px 제거
- 품질 검증(§5): 500장 무작위 추출 인간 재조재 "*94% of pairs have greater than 90% IoU*" — 기존 인간 합의 85–91% IoU와 대응 · **"99.1% fully automatically generated"** · 기존 최대 데이터셋 대비 **마스크 400× / 이미지 11×(Open Images)**

**(e) 평가 — 검증 가능 최소 셀**
- 1점 유효마스크(§7.1): 23 데이터셋(APDE20K·LVIS·OVIS·VISOR 등) — "SAM이 **16/23** 더 높음(최대 ~47 IoU)" 및 "oracle로 애매성 결정 시 **모든** 데이터셋에서 RITM 초과". ⚠ 절대 mIoU 수치는 **챠트 축 표기뿐** — 본문·표 수치 없음 → 숫자 기재 금지
- **인간 평가(LVIS v0.5 단일 점)**: 모델 평균점(10점): RITM **6.5** ← 표기 **7.7** ← **SAM 8.1** ← GT **8.5** (95% CI 표기 원문 Fig. 18)

- **객체 프로포절 LVIS v1 (Table 4, AR@1000)**: SAM **59.3** vs ViTDet-H **63.0**(small 45.5 vs 51.7, rare **65.8 vs 58.3** — rare에서 SAM 우위) (조건: 64×64 그리드·NMS 0.9, 이미지당 ~900 마스크)
- **인스턴스 분할 (Table 5)**: 프롬프팅 = ViTDet-H 박스 → SAM **COCO 46.5 / LVIS 44.7 AP** vs 완전 지도 VigTDet-H **51.0/46.6** (분할관이 zero-shot인 조건 명시)
- **텍스트-마스크(§7.5)**: "이 실험은 개념 검증" — **정량 표 없음** → 수치 기재 금지 (CLIP **ViT-L/14@336px** 사용 조건만 기술)
- **소거(§7.6)**: 자동마스크 전용 학습 —들이인 데이터 대비 **~0.5 mIoU** 미만 차이; **1M 이미지(~10%)면 총 SA-1B와 동등**; 인코더 스케일: "ViT-H는 ViT-B 대비 큰 개선, ViT-L 대비는 마진"

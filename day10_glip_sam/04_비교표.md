## 6. SAM 구성·출력 (§3 + App. §A)

| 요소 | 구성 조건 |
|---|---|
| 이미지 인코더 | MAE 사전학습 **ViT-H/16**, 14×14 windowed attention + 전체적 attention 4 블록, 입력 **1024×1024**, 임베딩 64×64 |
| 프롬프트 인코더 | 점/박스 = 위치 인코딩 + 타입 임베딩(256d), 텍스트 = CLIP 텍스트 인코더, dense(마스크) 프롬프트 = conv 체인 |
| 마스크 디코더 | **2층 transformer 디코더 블록**, dim 256, 8 heads, 출력 토큰이 **동적 선형 분류기**로 마스크 생성 |
| 출력 마스크 | **단일 프롬프트 = 3개**(whole/part/subpart 중첩) — **다중 프롬프트 = 1개**(4th 마스크는 다중 프롬프트에서만 회수) |
| 손실 | focal : dice = **20:1** (3개 각각, 하지만 **최저손실** 마스크에서만 학습信号的 전파) + IoU 두 MSE(스케일 1.0) |

## 7. SAM 데이터 엔진 — 3단계 (§4 + Fig. 6)

| 단계 | 이미지 | 누적 마스크 | 마스크/이미지 | 특이사항 |
|---|---|---|---|---|
| 1 보수-수동 | 120k | **4.3M** | 20 → 44 | 시간/마스크 34s→**14s**, 인코더 ViT-B→ViT-H 재학습 **6회** |
| 2 반자동 | +180k | **10.2M** | 44 → 72 | 박스 검출기로 사전특이점 채움 + 수동 마스크 정제, 재학습 5회 |
| 3 자동 | ~11M | **1.1B** | 평균 ~100 | 32×32 규칙 점 그리드(전체 + 20 crop), **99.1% 자동** |

- 품질 틀 (§B): 예측 IoU **88.0** 이하 제거, 안정성 IoU **95.0**, 이미지-전역 마스크(≥95% 면적) 제거, box NMS **0.7**, 100px 이하 잡 클러스터 제거.
- 검증: 500장 무작위 재측정 **"94% of pairs have greater than 90% IoU"**(기존 인간 합의 85–91% IoU 대상) — Open Images 대비 **마스크 400×-이미지 11×**.

## 10. GLIP vs SAM — 같은 데모 두 밴드 (직접 비교 ❌, 구조 대응 ◯)

| 관점 | GLIP | SAM |
|---|---|---|
| 문제 | 텍스트 조건 **탐지**(박스) | 프롬프트 조건 **분할**(마스크) |
| 프롬프트 | 문장(토큰, 256 한도 → 40 카테고리 청킹) | 점/박스/마스크/텍스트 |
| 인코더-디코더 몸집 | X-MHA 교차 어텐션 **딥퓨전**(O_t2i의 컨텍스트 여입) | ViT-H 이미지 인코더 **1회 사전계산** + 경량 디코더(<1% 연산) |
| 학습 시 무엇을 번다 | **grounding(복문) 데이터가 검출 rare를 끌어올림**(Table 5) | **자동 생성 마스크를 데이터가 폭도로 불리고, 모델 재학습이 라벨을 다시 질**: 서로 성장하는 나사|  |
| 조건 승부 | zero-shot GLIP-L **52.1** > 10-shot 지도 DyHead **50.8**(ODinW) | rare 프로젝트 AR **65.8** vs 58.3(ViTDet-H) |
| 데모 앵커 | V2 동등성(1.0) → V3 마진 항등식 방향 | V2 20:1 최소손실=최대 IoU(3/3) → V4 순수 focal 붕괴(0/3) |

> 둘은 문제(박스 vs 마스크)와 하드웨어 조건이 다르므로 **수치 상호 비교는 원칙적 금지**다. 공통으로 배울 수 있는 것은 ① "정답 각도를 학습시키면 zero-shot/few-shot 격차가 뒤집힐 수 있다", ② "모데내가 전부가 아니라 **데이터 파이프라인(라벨 파이프라인)이 원동력**"이다.

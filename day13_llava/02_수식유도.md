# 02 · 수식유도 — LLaVA (식 1~3의 정확한 구조)

> 논문: Visual Instruction Tuning (2304.08485). 근거: 00_검증팩트시트.md
> 성격: 논문 수식을 구연으로 정리 + 그 구조가 데모(`llava_demo.py`)의 V1~V4와 어떻게 대응되는지.

## 1. 식 (1) — 선형 projection

```
H_v = W·Z_v,   Z_v = g(X_v)
```

- Z_v: CLIP ViT-L/14가 주는 **그리드 피처** (마지막 Transformer 층 before/after 둘 다 고려)
- W: **trainable projection matrix** — 워드 임베딩 공간과 같은 차원으로 투영
- H_v: 투영된 **시각 토큰 수열** — LLM의 워드 임베딩 자리와 섞여 들어감

### 유도 방향 (관통 케이스)

projection이 선형이라는 것 자체가 데이터 측 실험을 빨리 반복하는 이유다.
W만 바꾸면 결합 전체를 재학습할 필요가 없고, 비전·LLM 양쪽 모듈을 건드리지 않은 채
'정합'이라는 변수 하나만 순간 교체할 수 있다.
데모 V1 = 이 W의 "정합"이 Stage 1에서 어떻게 얻어지는지 재현.

## 2. 식 (2) — 턴 구조

```
첫 턴:   X_instruct^1 ∈ { [X_q^1, X_v] , [X_v, X_q^1] }   (무작위)
이후 턴: X_instruct^t = X_q^t
```

- 이미지 토큰을 질문 앞/뒤 어느 쪽에 둘지 무작위로 섞는다 — 좌표계 과적합(자리 고정)을 막는 장치.
- 이 구조가 곧 Table 2의 시퀀스(assistant 답변만 초록)로 연결.

## 3. 식 (3) — 자기회귀 학습 목표

```
p(X_a | X_v, X_instruct) = ∏_{i=1..L} p_θ(x_i | X_v, X_instruct,<i , X_a,<i)
```

- 학습 대상 θ:
  - **Stage 1: θ = {W}**  (인코더·LLM 고정, 595K 1ep · lr 2e-3 · bs 128)
  - **Stage 2: θ = {W, φ}** (인코더 고정, 158K 3ep · lr 2e-5 · bs 32)
- loss 마스크: **assistant 답변 토큰만** 계산 — 논문 문구 "only green sequence/tokens are used to compute the loss".
- X_v를 모든 조건부에 명시 — 이미지가 grounding이라는 뜻.

### 데모 V3의 재해석

"loss 마스크가 미치는 기제" — instruction 토큰에 gradient가 들어가지 않는다는 것은
학습 신호를 답변 노력에 집중시킨다는 뜻이다.
데모 V3는 이 마스크의 동작(항등식·기울기 관문)을 합성 세계에서 확인한다.

## 4. 지시 데이터의 세 배열 (§3의 표 구조)

```
158K = 58K (conversation)  +  23K (detailed description)  +  77K (complex reasoning)
```

- 세 종류가 각기 다른 응답 품질 차원을 끌어올림.
- Table 4의 소비 배분이 이를 보증한다: reasoning 데이터의 '소량 혼입'까지 대화 성능을 추진(80.5 vs 73.8 등).

## 5. ScienceQA 앙상블의 논리 (§5.2)

```
LLaVA 단독 90.92  ·  GPT-4† (text-only, 저자 eval) 82.69
LLaVA + GPT-4 (judge) = 92.53
```

- 구조: 두 모델의 답이 다르면 GPT-4가 최종 판정.
- 관측(원문): 텍스트 전용 GPT-4가 이미지 문맥 문제에서 성능을 끌어올리는 이유는
  **이미지 없이도 답되는 문제를 식별·교정**하기 때문 — 판정 행위는 '보는 것'이 아니라
  '어휘만으로 결론이 나는 문항 가려내기'다.
- 수식상 성격: 모델 앙상블 — 판정 규칙이 결합 함수의 역할을 한다(데모 V4의 분해 확률).

## 6. 정리 (데모 대응 관계)

| 식/표 | 기제 | 데모 검증 |
|---|---|---|
| 식 (1) + Stage 1 | 선형 W의 정합 | V1 |
| Table 4 구조 | 3종 지시 데이터 혼입 → 능력 | V2 |
| 식 (3) + loss 마스크 | 답변 토큰 열만 학습 | V3 |
| Table 7/judge 논리 | 2모델 분기 → judge 앙상블 | V4 |

# Day 15-16 검증 팩트시트 — VL-JEPA (Vision-Language Joint Embedding Predictive Architecture)

> **논문**: arXiv [2512.10942](https://arxiv.org/abs/2512.10942)  
> **저자**: Meta FAIR & HKUST (Yann LeCun 등)  
> **목적**: 2026.11.02~11.03 세션을 위한 논문 수치 및 스펙 사전 검증

## 1. 모델 핵심 사양 (✅ 2026-11-02 v2 원문 확정)

- **X-Encoder (비전)**: 동결 V-JEPA 2 ViT-L, 304M (256² 해상도, 이미지는 복제해 16프레임 형태 주입)
- **Predictor**: Llama-3.2-1B 마지막 8층 초기화, 490M 학습가능. 쿼리 최대 512토큰, `[PAD]` 패딩, **causal mask 비활성화(양방향)**, non-PAD 토큰 평균풀링
- **Y-Encoder (텍스트 타깃)**: EmbeddingGemma-300M 초기화 (콘텍스트 512자). **LR multiplier ×0.05** (sweet spot 0.05~0.10)
- **공유 임베딩 공간**: 양측 linear projection 후 **1,536차원**
- **Loss**: 양방향 **InfoNCE** (정렬항 + 균일화항, Wang & Isola 2020) — EMA/L1/L2 미사용
- **학습**: 2단계 — (1) 쿼리 없는 캡션 사전학습: 이미지(Datacomp, YFCC-100M) 1프레임×100k iter 배치 24k → ImageNet zero-shot 61.6%, 이후 비디오(Action100M) 8프레임×60k → 32프레임×10k, 총 4주 / 24노드×8 H200, lr 5e-5 고정. (2) SFT: 83k 스텝 × 배치 3,072 (~2.5일) — 25M VQA + 2.8M 캡셔닝 + 1.8M 분류 + 사전학습 데이터 다운샘플
- **Y-Decoder**: 학습 미개입, 추론 시 필요할 때만 텍스트 해독

## 2. 팩트 대조 체크리스트 (✅ 검증 완료)

- [x] ~~타깃 인코더 EMA 모멘텀 스케줄링 값~~ → **EMA 미사용**. InfoNCE(균일화항)로 anti-collapse. frozen Y-encoder는 대안 전략으로 언급 (Zhou et al. 2025). Y-encoder는 ×0.05 LR로 soft-freeze 학습
- [x] ~~마스킹 전략~~ → **VL-JEPA 학습에 마스킹 없음** (전체 프레임 입력). 마스킹은 동결 X-Encoder의 upstream(V-JEPA 2) 레시피 소관 — 본문에 비율 미기재
- [x] 텍스트 주입 지점 → **Predictor 입력단에 쿼리 토큰 결합** (텍스트 토큰 임베딩을 비전 토큰과 함께 주입, 양방향 어텐션). 인코더 내부 주입 없음
- [x] 다운스트림 평가 벤치마크 (v2 기준):
  - 비디오 분류 8셋 (SSv2, EK100, EgoExo4D, K400, COIN SR/TR, CrossTask SR/TR): BASE 평균 **52.5** (vs PE-Core-G 44.7), SFT 평균 **75.4**
  - 텍스트→비디오 검색 8셋 (MSR-VTT, ActivityNet, DiDeMo, MSVD, YouCook2, PVD-Bench, Dream-1k, VDC-1k): BASE 평균 Recall@1 **63.7** (vs 58.1)
  - VQA 4셋: **GQA 61.5 / TallyQA 69.9 / POPE 85.7 / POPEv2 86.3** (1.6B)
  - **WorldPrediction-WM**: 63.9 (BASE) / **65.7 (SFT, SoTA)** — GPT-4o, Claude-3.5, Gemini-2 초과
  - **§4.4 Action Anticipation (v2 신규)**: EK100 Recall@5 t=1/2/4/10s = **34.2/26.0/19.4/11.7** (동일 인코더 V-JEPA2 ViT-L-256px 초과, 전 갭), COIN 다음-스텝 **56.2 SoTA**
  - Y-Encoder 독립 평가 (SugarCrepe++/VISLA): BASE 평균 **49.8/42.9** (CLIP 37.6/31.3, SigLIP2 48.7/32.1, PE-Core-G 45.2/31.4 대비 전원 우세)
  - 통제 비교 (§4.5): 동일 PE ViT-L-14 인코더·데이터·배치에서 15M 샘플 시 **14.8 CIDEr vs 7.1**, top-5 **41.0% vs 27.2%**, 학습 파라미터 50% 이하
  - Selective decoding: 0.35Hz 적응 선택이 uniform 1Hz와 등가 → 디코딩 **2.85× 절감**

> ** ✅ 2026-11-02 교차 검증 마무리 (원 3건 모두 해소)**:
> 1. **X-Encoder upstream 마스킹 비율 확정** — V-JEPA 2 (2506.09985)는 비율을 V-JEPA (2404.08471)에 회부; **3D Multi-Block masking**, short-range(스케일 0.15, 8블록) + long-range(스케일 0.70, 2블록) 멀티마스킹, 평균 마스킹 비율 **≈ 90%** (encoder측), tubelet 2×16×16
> 2. **Samples seen 해석 확정** — 표 1 수치는 **누적** 기준: BASE 3.3B(이미지 2.4B + 비디오 ≈0.9B), SFT 3.6B(3.3B + 83k×3,072≈0.25B). §4.1 본문 "only 3.6B"와 부합
> 3. **Ablation (c) 캡션 확정** — "(with no projection head on top frozen text encoder)": 4개 loss 로우 전부 **동결 인코더 + 프로젝션 헤드 없음** 조건 비교. InfoNCE의 균일화 이득이 동결 타깃에서도 실측됨 (cosine 대비 -6.8/-10.1)
> 4. **신규 확보 — ablation (b) multiplier 행**: ×0.00(완전 동결) 분류 20.0/검색 25.9/41.4(-7.3/-4.3/-1.1) — **비붕괴는 성립하나 의미 적합 부재 비용 실측**; ×1.00도 하락. Sweet spot ×0.05~0.10

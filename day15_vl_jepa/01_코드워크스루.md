# 01 · 코드워크스루 — VL-JEPA 아키텍처 및 텐서 파이프라인

> **대상**: VL-JEPA (arXiv 2512.10942 v2)  
> **세션 일자**: 2026.11.02(월) ~ 11.03(화)  
> **✅ 2026-11-02 원문 대조 교정**: 아래 다이어그램은 일반 JEPA 구조이며, 실제 VL-JEPA의 확정 사양은 다음과 같다 — (1) 모듈별 정보가 달라짐: X-Encoder와 Target Encoder가 아닌 **X-Encoder(동결)+Y-Encoder(텍스트 타깃)** 2-encoder 구조, (2) 언어 쿼리 $X_Q$는 Predictor 입력단 결합, (3) **EMA 타깃 업데이터는 존재하지 않음** — 학습 목적으로는 InfoNCE를 채택. 세부 라이브 스펙은 [`00_검증팩트시트.md`](00_검증팩트시트.md) 참조.

## 1. 아키텍처 전체 흐름

```
[비전 입력 (Frames / Patches)] ──> [X-Encoder (동결 V-JEPA 2 ViT-L, 304M)] ──> S_V (토큰 시퀀스)
                                                                                  │  P_vis (linear proj → 1536d)
[언어 쿼리 X_Q] ──> [Llama-3.2-1B Tokenizer/Embed ─────────────┐              │
                   쿼리 토큰 (최대 512, [PAD] 패딩)] ──────────┼──────────────┴──> [Predictor (Llama-3.2-1B 마지막 8층, 490M)]
                                                                                 causal mask OFF, 양방향 어텐션
                                                                                 │
                                                                                 v  non-PAD 토큰 평균풀링
                                                                              Ŝ_Y (예측된 타깃 텍스트 임베딩)
                                                                                 │
[텍스트 타깃 Y (정답/캡션)] ──> [Y-Encoder (EmbeddingGemma-300M, LR×0.05)] ──> S_Y ── ∥ 양방향 InfoNCE(정렬+균일화)
                                                                                 │
[Y-Decoder (S^Y→Y^)] — 학습 미개입, 추론 시 필요할 때만 (selective decoding 2.85× 절감 지원)
```

## 2. 핵심 모듈별 라인바이런 (v2 원문 스펙 확정)

1. **X-Encoder**: 비전 인코더는 **동결된 V-JEPA 2 ViT-L** (304M) — 마스킹 없이 전체 프레임을 토큰 시퀀스 S_V로 인코딩 (512토큰 쿼리 + 비전 토큰 결합 전 양측 linear projection으로 1,536d 통일)
2. **Predictor**: Llama-3.2-1B **마지막 8 Transformer 층** 초기화, 490M 학습가능. 쿼리 토큰 당 **maximum 512** 입력 쿼리 토큰 허용, `[PAD]` 패딩, **causal mask OFF** (§3.1) — 셀프어텐션으로 비전↔텍스트 cross-reasoning
3. **Y-Encoder**: EmbeddingGemma-300M 초기화 (LR multiplier **×0.05**, ablation sweet spot 0.05~0.10) — *텍스트 임베딩 모델*, InfoNCE로 **joint-training** (EMA 아님)
4. **Y-Decoder**: 사전학습·SFT 모두 **학습 미개입**; 추론 시 임베딩을 텍스트로 해독 — "encoding prediction vs token prediction"의 인프라스 추상 계층
5. **Loss**: 양방향 InfoNCE = 정렬항 + 균일화항 (§2, Wang & Isola 2020 분해) — 세부는 [`02_수식유도.md`](02_수식유도.md)

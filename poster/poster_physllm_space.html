G0 · week 1Pilot: is the residual stream measurable?

First question: do layer-wise hidden-state norms and updates Δhl = hl+1 − hl come out finite and correctly shaped?

N02 · week 2Three observables, frozen

Small HF causal LMs (gpt2, pythia-160m, 12 blocks) instrumented block by block, with the observable set frozen for traceability:

1length-adjusted update norm ‖hl+1−hl‖F/√T
2input–update cosine cos(hl, Δhl)
3output/input norm ratio

N02 · resultCosine flips sign with depth

Cosine rises, then turns negative in the last blocks (GPT-2 −0.769 at block 11; Pythia −0.840 at block 10).

N02 · resultAttention vs MLP branch

Attention dominates GPT-2 (cosine 0.37–0.43) while Pythia is MLP-dominant (0.72–0.76) — the same observable, two architectures.

N03 · week 3Three branches, one active

N02 deferred three architecture families; N03 registers them as candidates and runs M1 (MoE routing-conditional). M2 (MLA latent attention) and M3 (SSM / hybrid) stay design-stage only — no claim may use them yet.

N03 · observablesRouting, not just residuals

Residual stream measures are inherited from N02; N03 adds the branch split and the router:

attn_shareattn²/(attn²+moe²) of the pre-residual output
routingtop-4 expert ids + gate weights (softmax over the top-k logits, not the full 128)
entropyrouting entropy and H/ln k (k = 4)
loadper-text/layer expert load histogram

N03 · resultResidual ratio falls, routing stays flat

Output/input ratio 1.351 → 1.234 → 1.137 across early/middle/late blocks, while routing entropy stays near uniform (H/ln4 ≈ 0.95–0.98).

N03 · infrastructure80 GB is a hard wall

MXFP4 weights ≈ 60.8 GB; 8K context ≈ 65.8 GB, 32K ≈ 68.6 GB.

Minimum: one 80 GB GPU (A100 80GB / H100 80GB / MI300X). L4 24GB, T4 16GB, A100 40GB are insufficient. Runtime: Triton ≥ 3.4, compute capability ≥ 7.5.

Development uses gpt-oss-20b (~16 GB) only for pipeline wiring.

N03 · gatesProvenance is enforced, not documented

Every capture must pass the dataset gates (G1, M1–M5, P1) and ships provenance:

shamanifest SHA-256 · code SHA + git revision/dirty
metatokenizer ID · activation dtype · seed 0 · package versions
tests30 gate tests passing (incl. an independent routing recomputation)

Resume is idempotent and refuses to append into an out-dir captured from a different manifest.

N03 · auditT0: three texts out of band

The tokenizer audit recomputes token counts for every candidate text. gpt2 and pythia-160m come back clean (0 mismatches).

gpt-oss leaves 3 long-tier texts out of band (127–128 tokens against a 129 floor) — and they are not random: 11 of 33 long × question_dialogue texts now sit within 2 tokens of the floor, while other long styles clear it by 21+ tokens.

Options A / B / B' / C are quantified in the decision memo — choice pending.

Across generationsWhat carries forward

One observable definition survives every generation:

Δhl = hl+1 − hl  ·  ‖Δhl‖F/√T  ·  cos(hl, Δhl)

G0 asked whether it is measurable, N02 froze what to measure and how to sample, N03 reuses both and adds the router — with the same gates, the same SHA-256 discipline and the same habit of stating the limits next to the number.

LimitsStated next to the numbers

• Exploratory descriptive statistics — no causal or topic-clustered inference.
• No independent validation against the model's real router dispatch or an fp32 reference run.
• Candidate manifest not frozen for confirmatory analysis.
• N02 pilot is 5 prompts per model; N03 blocks are a capture, not a behavioural claim.
• Max relative branch-identity residual 0.0187 (N03) · 2.3e-5 (N02).

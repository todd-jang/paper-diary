Matching before the loss

The Hungarian algorithm finds the globally optimal one-to-one assignment between prediction slots and ground-truth objects, so duplicates become structurally impossible.

L = Lclass + λ1L1 + λGLGIoU

Matching cost uses probabilities (bounded, commensurable with the box term); the loss uses log-likelihoods. Under the same 15% relative error, L1 penalises a large box 9.44× more than a small one, while GIoU stays at 1.000×.

02 · The NMS dilemmaTwo thresholds, one trade-off

Paper Table 1 (YOLOv8, T4 · TensorRT FP16): raising the confidence threshold removes candidates — faster but less accurate; raising the IoU threshold suppresses fewer boxes — more accurate but slower.

YOLO papers report model speed excluding NMS time, so RT-DETR builds an end-to-end benchmark (§3.2) with the NMS plugin included.

03 · Bottleneck → designWhy is AIFI only on S5?

In Deformable-DETR the encoder consumes 49% of GFLOPs for 11% of AP (a second-hand statistic, not our measurement). RT-DETR re-architects it:

AIFIself-attention on S5 only (400 tokens)
CCFFconv-based cross-scale fusion (linear cost)

Attention cost grows with M²: 8400 candidate tokens vs 400 on S5 is a 441× gap. Variant D_S5: latency −35% and AP +0.4.

04 · Query qualityWhat does uncertainty change?

U = ‖P − C‖ — the mismatch between the location and classification prediction of a feature — enters the loss, so the encoder learns features that agree in both.

AP47.9 → 48.7   Prop cls0.35% → 0.82%   Prop both0.30% → 0.67%

Selection ≠ objective: the public top-K still ranks by class score (rtdetr_decoder.py:491) — uncertainty changes the loss, not the ranking.

05 · Inference controlTune speed with depth

Auxiliary heads train every decoder layer, so inference can stop early without retraining. Paper Table 5 (Det 6): 6 layers 53.1 AP / 9.3 ms → 5 layers 53.0 / 8.8 ms → 1 layer 49.1 / 7.0 ms.

Cost per layer is nearly constant (0.4–0.5 ms) while the accuracy gain shrinks with depth (+2.2 AP at layer 1→2, only +0.1 at 5→6).

eval_idx = which layer max_det = output cap lower max_det ≠ faster

07 · Open limitsWhat remains unresolved

  • Small objects stay weak — APS 34.8 (−0.5 vs YOLOv8-L; R101 −0.9): the cost of restricting global attention to S5 while keeping multi-scale features.
  • 49% / 11% is a second-hand statistic — cited, not measured by us.
  • 138% / 120% are relative counts, not percentage-point gains.
  • 2D COCO only — depth, BEV and multi-view remain untested.
